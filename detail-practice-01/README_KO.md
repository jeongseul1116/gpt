# 디테일 연습 01 — 7쪽 가보자고

이 연습의 목표는 폰트 견본을 먼저 보고 느낌과 이유를 함께 읽게 하는 것이다. 2열 10서체와 11pt 견본을 유지하면서 카드 여백, 설명의 무게, 문장 간격, 기준선을 조정했다. 지면의 텍스트는 바꾸지 않았다.

## 비교 자료

- Detail_Practice01_Review_Board.png: 수정 전후를 나란히 보는 연습 보드.
- PDF/Detail_Practice01_Before_After.pdf: 1쪽은 수정 전, 2쪽은 연습 시안. 각 장 A5 148×210mm.
- PDF/Detail_Practice01_Review_Board.pdf: 비교 보드를 크게 보는 A3 가로 안내 자료.
- editable/Meme_Font_Book_Detail_Practice01_28p.idml: 7쪽만 연습 시안인 28쪽 편집 파일.
- editable/Create_Detail_Practice01_28p.jsx: 같은 연습 파일을 InDesign 안에서 만드는 스크립트.

IDML·JSX 옆에 Links 폴더를 유지한다. 편집에는 font_records의 정확한 서체와 스타일이 필요하다. 서체 원본은 동봉하지 않았다. IDML·JSX는 구조, 내용, 좌표, 서체, 문법을 검수했다. 실제 InDesign 실행과 프로그램 안에서의 기준선 정렬은 미검증이다.

이번 파일은 별도 연습 시안이다. 기존 최종본 28쪽 PDF·IDML·기획안·출력본은 그대로 두었고, 연습용 편집 파일의 다른 27쪽도 기존과 같다. Google Docs 기획안과 A3 출력본의 새 제출 버전은 이 연습 묶음에 포함하지 않았다.

## 직접 해볼 순서

1. 여백: 카드 안쪽 좌우를 8pt에서 10pt로, 서체 이름 글상자의 상단 간격을 2pt에서 6pt로 맞춘다. 카드 높이는 67pt에서 63pt로 줄이고 행 간격을 6pt로 만든다. 두 열 사이는 8pt에서 12pt로 넓힌다.
2. 문장 묶음: 느낌과 이유 글상자의 시작 간격을 19.2pt에서 12pt로 줄인다. 두 문장이 한 묶음으로 읽히는지 본다.
3. 정보 위계: 설명의 7.2pt 크기는 유지하고 서체를 YES24에서 Noto Sans CJK KR Regular로 바꾼다. 같은 크기에서 획의 무게가 달라지는 효과를 본다.
4. 기준선: 11pt 견본을 유지하고 각 행의 글자가 같은 기준선에 놓이도록 글상자의 높이와 위치를 조정한다. 각 행 기준선은 지면 위에서 174·243·312·381·450pt다. 글상자의 위쪽 선과 글자의 기준선은 구별해서 본다.

수치의 간격은 글상자와 카드의 경계를 기준으로 한다. 1pt는 약 0.353mm다. 전후 PDF는 실제 크기 100%로 보면 작은 글씨의 읽힘을 판단하기 쉽다.

## 스스로 확인할 것

- 페이지를 잠깐 봤을 때 어떤 문구가 가장 먼저 보이는가?
- 느낌과 이유가 한 묶음으로 읽히는가?
- 왼쪽과 오른쪽 견본을 번갈아 볼 때 바닥선이 안정적인가?
- 글상자 위치가 같아도 서체에 따라 글자의 실제 위치가 달라지는가?

한 항목씩 조정한 뒤 전후를 비교한다. 서로 다른 조정이 읽는 순서에 주는 영향을 구별하는 것이 이번 연습이다.
