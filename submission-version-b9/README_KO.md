# B9 — 말투수집실 전체판

[전체 28쪽 PDF](Meme_Font_Book_Version_B9_28p_Review.pdf) · [A3 양면 인쇄 PDF](Meme_Font_Book_Version_B9_A3_Duplex_28p.pdf)

승인한 검정·노랑·빨강·파랑 전단 스타일을 전체에 적용했습니다. 비교 문장은 ‘북쪽에계신메리메리’입니다. 12폰트의 문장 전체, 글자 전체 외곽과 모든 8간격을 보고, 형태의 근거를 개인적인 B급 말투 인상으로 연결합니다. 검토한 유행어 15개는 후반에 배치했습니다. ‘들어가며’부터 1쪽이며 표지·목차·뒷표지는 무쪽수입니다. 이전 판과 샘플은 보존했습니다.

인쇄는 **A3 가로 · 실제 크기 100% · 짧은 쪽 양면**으로 설정합니다. 총 7장, 앞뒤 14면입니다. 파일 자체가 이미 소책자 순서로 배치되어 있으므로 소책자·모아찍기·용지맞춤은 해제합니다. 첫 면 28｜1, 다음 면 2｜27은 표지를 포함한 PDF 순서입니다. 3mm 도련, 재단선, 100mm 확인선을 포함했습니다. 완성 크기는 A5 148×210mm입니다.
