# 추가 네 서체의 실제 파일과 라이선스 기록

이 기록의 글꼴은 기존 예스체·Noto 고딕·명조와 별도로 실제 견본에 사용할 네 서체다. 글꼴 원본 바이너리는 제출 ZIP에 동봉하지 않는다.

| 표시 이름 | 실제 family 와 style | 배포·사용 기록 |
| --- | --- | --- |
| 은궁서 | UnGungseo Regular | Debian 공식 fonts-unfonts-core 패키지. GPL-2. 원본 글꼴을 배포하지 않고 지면은 글리프 윤곽으로 출력한다. 패키지 copyright와 GPL-2 원문을 함께 보관한다. |
| 주아 | Jua Regular | Google Fonts 공식 저장소 파일 및 SIL OFL 1.1 원문. |
| 나눔손글씨 붓 | Nanum Brush Script Regular | Google Fonts 공식 저장소 파일 및 SIL OFL 1.1 원문. |
| 둥근모꼴 | DungGeunMo Normal | 폰트 내 Public Domain 선언. 공식 Neo둥근모 README가 원형 둥근모꼴의 공개영역 배포 사실을 확인한다. Neo둥근모 폰트 자체와 구분한다. |

은궁서 공식 패키지: https://deb.debian.org/debian/pool/main/f/fonts-unfonts-core/fonts-unfonts-core_1.0.2-080608-23_all.deb

은궁서 업스트림 소스: https://deb.debian.org/debian/pool/main/f/fonts-unfonts-core/fonts-unfonts-core_1.0.2-080608.orig.tar.xz

주아: https://raw.githubusercontent.com/google/fonts/main/ofl/jua/Jua-Regular.ttf

나눔손글씨 붓: https://raw.githubusercontent.com/google/fonts/main/ofl/nanumbrushscript/NanumBrushScript-Regular.ttf

둥근모꼴 배포 파일: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_six@1.2/DungGeunMo.woff

둥근모꼴 원형 설명: https://raw.githubusercontent.com/Dalgona/neodgm/master/README.md

Microsoft Windows 기본 궁서는 현재 설치되어 있지 않다. 이번 견본의 궁서계열은 위 실제 은궁서다.

‘양제샤넬체’는 사용자가 지칭한 정확한 파일을 확보하지 못했다. ‘양재샤넬체’일 가능성은 있으나 확정하지 않는다. 허가된 실제 파일이 제공되기 전 다른 서체를 해당 이름으로 표시하지 않는다.

조선궁서체 파일은 확보했으나 공식 사용약관 페이지는 네트워크 403으로 확인하지 못했으므로 선택된 네 서체에 포함하지 않았다.
