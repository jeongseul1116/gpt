# 세 번의 숨 고르기

총28면을 유지하며 인쇄쪽수07·13·21의 기존 밈 시작면을 환기 면으로 다시 조판했습니다. 빈 페이지를 덧붙이지 않고, 같은 카드가 반복되는 흐름 안에서 읽는 속도와 시각적 밀도가 달라지도록 했습니다.

- 07쪽 — 과잉 고백 포스터: 분홍 바탕 한 면과 큰 제목 「커피 한 잔에 / 장르가 바뀜.」으로 분위기를 키웁니다. 사랑 밈 원문10행과 사용 상황·대화는 그대로입니다.
- 13쪽 — 작은 정정문: 여섯 원문 행의 글씨가17→15→13→11→9→7.5pt로 작아지며 자신감이 줄어드는 말투를 보입니다. 여섯 폰트 비교는 박스 없는 세로 목록으로 바꿨습니다. 비교 견본은 기존11pt·폰트·검정·자간·비율을 유지했습니다.
- 21쪽 — 새벽 혼잣말: 상자를 걷고 흰 종이와 넓은 여백 안에 원문을 둡니다. 끊어진 자모와 마침표까지 보존했고, 마지막 마침표만 따로 남지 않도록 줄폭을 조정했습니다.

목차의 해당 세 항목에 ‘숨 고르기’를 표시했습니다. 페이지 순서와 범위는 같습니다. 본문 다른24면은 검토이미지에서 기존판과 같고, 목차를 포함해 실제로 바뀐 면은4면입니다. 표지·쪽수·원문·비교견본126개·TF도해21개는 유지했습니다. 표지 사진과 도해는 파일 내부에 들어 있습니다.

인쇄쪽수01은 목차이며 표지·뒷표지는 번호가 없습니다. 파일의 물리 페이지08·14·22가 인쇄쪽수07·13·21입니다. PDF뷰어도 표지/1–26/뒤표지로 표시합니다. 기존에 제공한 폰트11종과 YES24.ttf를 설치한 뒤 IDML을 열어 INDD로 저장하면 됩니다.

이전 작업에서 사용자 수정INDD를 읽어 변환한 최신IDML을 기준으로 작업했습니다. 원본INDD는 변경하지 않았습니다. IDML의 원고·참조·이미지·문서 구조와 변경 범위를 독립 비교했고, 검토PDF의 새 세 면과 전체 구성을 확인했습니다. 실제 Adobe InDesign 열기·저장·줄바꿈·넘침과 최종 인쇄는 이 환경에서 미검증입니다. 검토PDF는 근사 렌더이므로 최종 인쇄용 인증본이 아닙니다.
