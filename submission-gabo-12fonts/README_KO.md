# 가보자고와 12서체 수정본 28쪽

첫 출발 문구를 가보자고로 정리하고 제목·비교 견본·답장 예문에 모두 반영했습니다. 실제 서체는12종입니다. 새로 더한 Black Han Sans·Gugi·Kirang Haerang·Single Day·Black And White Picture를 실제 지면에 적용해 큰 외침, 기계적인 글씨, 삐뚤한 손글씨, 거친 질감을 비교합니다.

2–3쪽 반표제와 서문, 27쪽 짧은 말 모음의 위치는 앞서 정리한 구성입니다. 4–5쪽은 같은 진심입니다를18pt 열두 서체로 비교하는 도감입니다. 얼굴 이모티콘과 AA 그림은 지면에 사용하지 않았습니다. 전체는 A5 세로28쪽, 밈15개입니다.

## 현재 제출 파일

- PDF/Meme_Font_Book_28p_Gabo_12Fonts.pdf: 전체 디자인28쪽.
- PDF/Meme_Font_Book_28p_Gabo_12Fonts_Spreads.pdf: 같은28쪽의 독서 순서 펼침면15면.
- PDF/Meme_Font_Book_28p_Gabo_12Fonts_A3_Print.pdf: A3가로14장,실제크기·도련3mm·재단선.
- editable/Meme_Font_Book_Gabo_12Fonts_28p.idml: 현재 지면의 편집 원본.
- editable/Create_Gabo_12Fonts_28p.jsx: InDesign 안에서 새 INDD를 만드는 스크립트.
- Planning_Gabo_12Fonts_GoogleDocs.docx: 현재12서체와 페이지 구성을 반영한8쪽 기획안.

Gabo_06_07.png는 교체한 문구와 세 서체 비교, Twelve_Font_Atlas_04_05.png는 열두 서체 전체 비교입니다. 모든 미리보기는 현재 PDF에서 새로 렌더했습니다.

## 편집과 출력

IDML 또는 JSX 옆에 Links 폴더를 유지하세요. 폰트 원본은 동봉하지 않았습니다. 편집에는 font_records/font_catalog.json의 실제12서체가 필요하며 정확한 family·style과 공식 출처를 기록했습니다. PDF는 글꼴 설치 없이 열 수 있습니다. 예스체는 하위집합으로 내장했고, 다른11서체는 실제 글리프의 벡터 윤곽으로 출력했습니다.

IDML·JSX는 구조·내용·폰트·좌표와 문법을 정적 검수했으며 실제 InDesign 실행은 미검증입니다. JSX가 만드는 새 원본 이름은 Meme_Font_Book_Gabo_12Fonts_28p입니다.

A3 출력은 PRINT_GUIDE_KO.md에 따라 가로·단면·실제크기100%로 설정합니다. 첫 장100mm 기준선을 확인한 뒤 바깥 재단선만 자릅니다. 실제 프린터 출력은 별도 확인해야 합니다.

기획안은 Google Drive에 업로드해 Google 문서로 연 다음 Google 문서로 저장해 제출할 수 있습니다. Google Docs 문서 자체를 직접 생성하거나 공유 설정을 바꾸지는 않았습니다.

## 원문과 교체 버전

기존 원문17개와 보존 파일은 작업 보관 위치에 그대로 유지했습니다. 가보자고는 별도의 교체 버전이며 user_replacements에 기록했습니다. 지면의 발췌·표정 제외 편집본은 display_editions.json에 구분했습니다. 이번 ZIP에는 현재 제출물과 편집 데이터만 담았습니다.
