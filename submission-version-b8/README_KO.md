# B8 — 좌우 외곽 둘, 그 사이의 흰 간격

[28쪽 PDF](Meme_Font_Book_Version_B8_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B8_28p.idml) · [A3 인쇄 PDF](Meme_Font_Book_Version_B8_A3_Duplex_28p.pdf)

참고 사진의 방식을 다시 읽어, 지면16–17쪽을 두 개의 마주 보는 외곽 도형으로 바꿨습니다. 실제 글자쌍 옆에 왼쪽 글자와 오른쪽 글자의 옆모양을 각각 진한·옅은 파랑으로 단순화합니다. 그 사이 흰 간격이 읽히도록 배치합니다. 빈틈 하나를 색칠해 꺼내던 주황 도형과 다른 방식입니다.

비교 문장은 **북쪽에계신메리메리**이며 모든8간격을 다룹니다. 01북–쪽부터08메–리까지, 반복된메리06/08도 각각 표시합니다. 실제 글자쌍과 두 외곽 도형은 같은36pt 원래 모양에서 얻습니다. 두 도형의 상호 위치를 유지한 채 그룹 전체를 영역 중앙에 놓습니다. 참고 책의 글자그룹 번호나 폰트 내부 커닝값을 임의로 옮기지 않습니다.

도형은 형태를 읽는 근거입니다. Noto Sans의 고른 획과 반복되는 외곽은 ‘내겐 안내방송 같은 인사’, 은궁서의 굵기 변화와 휘는 붓획은 ‘내겐 왕명 같은 인사’라는 편집자의 B급 인상으로 연결합니다. 간격 하나만으로 감정이 결정된다는 점수표는 아닙니다.

새로 바꾼 것은 목차 항목과 해당 두 페이지입니다. 나머지25쪽은 B7 그대로이며, 12종 폰트의 모든8간격 표시·전후 비교·8칸 조정표·승인 유행어15개·표지 중앙 정렬·내장 사진을 보존합니다.

A5 28면, 목차 무쪽수·들어가며부터1–25쪽입니다. 인쇄는 A3가로7장/14면·짧은 쪽 양면·실제100%입니다. 소책자·모아찍기·용지맞춤을 해제합니다. 첫28｜1·뒤2｜27은 표지 포함 파일 순서입니다. 3mm도련·재단선·100mm확인선을 포함합니다.
