# 표지 이미지 연결 복구

이 패키지에는 표지 사진 PNG와, 열려 있는 InDesign 문서의 표지 이미지만 복구해 문서에 포함시키는 스크립트가 있습니다. 수정하던 문서를 새로 만들거나 본문·폰트·쪽수·배치를 다시 적용하지 않습니다.

## 이미 수정 중인 문서에 적용

1. ZIP을 압축 해제합니다.
2. InDesign에서 수정 중인 문서를 엽니다.
3. ‘창 → 유틸리티 → 스크립트’를 엽니다. 사용자 폴더를 오른쪽 클릭해 ‘탐색기에 표시’를 선택합니다.
4. Recover_Cover_Image.jsx를 그 폴더에 복사합니다.
5. InDesign의 스크립트 목록에서 Recover_Cover_Image.jsx를 더블클릭합니다.
6. 완료 안내를 확인한 뒤 문서를 저장합니다. 필요하면 INDD로 다른 이름으로 저장합니다.

스크립트 안에 사진 데이터가 들어 있습니다. Links폴더를 찾지 못하더라도 실행할 수 있습니다. 기존 표지 링크 또는 ‘Cover meme photo’ 프레임을 찾아 그 이미지에만 적용합니다. 인식할 표지 프레임이 없으면 다른 이미지를 추측해서 변경하지 않고 중단합니다. 문서는 자동으로 저장하거나 덮어쓰지 않습니다. 실행한 변경은 한 번의 실행 취소로 되돌릴 수 있도록 묶었습니다.

## 스크립트를 사용하지 않는 경우

‘창 → 링크’에서 누락된 cover_cutout.png를 선택하고 ‘다시 연결’로 이 패키지의 Links/cover_cutout.png를 지정합니다. 그다음 링크 패널 메뉴에서 ‘링크 포함’을 선택해 문서에 포함시키고 저장하세요. 포함이 완료되면 그 표지 이미지는 외부 파일에 의존하지 않습니다.

## 포함 파일

- Recover_Cover_Image.jsx: 현재 문서의 표지 이미지 연결·포함용. 사진 데이터 내장.
- Links/cover_cutout.png: 복원한 타원 전체가 보이는 874×1275px·300dpi 사진.
- Meme_Font_Book_System_28p.idml: 이전에 전달한 최신 IDML과 같은 파일. 수정 중인 파일을 대신 열 필요는 없습니다. 새로 시작할 경우 Links폴더와 함께 두고 위 방법으로 이미지를 포함시키세요.

기존 ZIP 안에도 같은 이름의 PNG가 있었으며 파일의 누락·손상이나 대소문자 불일치는 확인되지 않았습니다. IDML의 사진은 외부 링크이며, 사용자의 컴퓨터에서 누락으로 표시된 정확한 원인은 이 환경에서 확인할 수 없습니다.

스크립트는 문서 내용과 표지 위치를 보존하도록 작성하고 구문 검사·모의 문서 테스트와 이미지 바이트 대조를 수행했습니다. 이 환경에는 Adobe InDesign이 없어 실제 앱 실행은 검증하지 못했습니다.
