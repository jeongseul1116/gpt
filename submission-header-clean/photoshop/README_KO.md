# 타원 오른쪽 끝 수동 복원

Cover_Oval_Restored.psd는 흰 배경·원본 사진·복원한 오른쪽 끝을 분리한3레이어 PSD입니다. 원본의 오른쪽 약28px를 이어 타원 전체가 보이게 하고 캔버스를1062×1550px로 넓혔습니다. 붉은 질감은 기존 오른쪽 가장자리에서 복제했고 얼굴과 흰 글씨를 새로 만들지 않았습니다.

Original_Source.png는 변경하지 않은 보관 원본입니다. Restored_Photo_Master.png는 투명 배경 합성본이며 PNG/PSD는300dpi로 설정했습니다. 책에 배치한 파일은300dpi·874×1275px입니다.

이 환경에는 Adobe Photoshop이 없어 프로그램을 직접 실행하지 않았습니다. ImageMagick으로 수동 클론 패치와 PSD레이어를 작성하고 독립 PSD파서로 구조·3레이어·합성 순서를 검사했습니다. 원본 파일은 바꾸지 않았습니다. PSD준비 과정의 알파합성 재인코딩으로 일부RGB값에 최대1/255 반올림 차이가 있습니다.
