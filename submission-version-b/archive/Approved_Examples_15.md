# 예문 확정 원고 — 1차 수정

사용자의 항목별 검토를 반영한 **15개 확정 원고**입니다. 대화6개와 상황 설명1개, 총7개 스토리 블록을 수정합니다. 나머지는 그대로 유지합니다. 표기의 띄어쓰기·어투·기호를 교정하지 않았습니다.

밈 원문은 별도 자료로 유지합니다. 아래 변경은 사용 상황과 대화 예문에만 적용합니다.

## 승인 진행

1. 현재 지면의15개 예문을 추출해 검토 목록으로 제시했습니다.
2. 사용자가 전체15항목을 검토하고7개 스토리 블록의 변경을 확정했습니다.
3. 아래 원고를 최종 반영 대상으로 정리했습니다. 준비 과정에서 IDML 파일은 수정하지 않았습니다.

## E01 · 5쪽 · 01. 일단 가보자고

**사용자 확인 완료** · 수정

사용 상황:

```text
준비는 덜 됐는데 누군가는 시작해야 할 때.
```

대화 예문:

```text
친구: 미친 시험 내일임ㅋ; 벼락치기 간다
→ 가보자고
```

수정 전:

```text
친구: 자료 조사는 누가 할래?
→ 가보자고
```
