# 밈 폰트 도감 — 32쪽 디자인 초안

A5 세로 148×210mm, 중철을 전제로 한 32쪽, 문서 도련 사방 3mm입니다. 표지 1쪽 + 본문 15개 펼침면 + 뒷표지 1쪽으로 구성했습니다. 인쇄소용 중철 판짜기는 적용하지 않았습니다.

## InDesign에서 열기

`Meme_Typography_32p.idml`을 InDesign에서 엽니다. 본문용 Noto Sans CJK KR·Noto Serif CJK KR의 Regular/Bold가 필요합니다. 공식 무료 배포: https://github.com/notofonts/noto-cjk

기본 한글 서체 계열로 구성했으며, 유료 폰트를 전제하지 않습니다. 누락 서체·기호 모양·텍스트 넘침·쪽 순서를 확인한 뒤 `.indd`로 저장하세요.

IDML 열기에 문제가 있거나 설치된 Windows 서체를 사용하려면 `Create_32p_InDesign.jsx`를 사용하세요. InDesign의 **창 → 유틸리티 → 스크립트**에서 사용자 폴더를 탐색기에 표시하고 파일을 넣은 뒤, 스크립트 패널에서 두 번 클릭합니다. 저장 폴더를 선택하면 InDesign 자체가 새 `.indd`를 저장하고 IDML도 내보냅니다. 맑은 고딕·바탕 등 설치된 서체로 대체할 수 있으며, 실제 사용 서체와 넘침을 보고서에 기록합니다. 기존 파일은 덮어쓰지 않습니다.

**이 환경에서는 InDesign을 실행하지 못했습니다.** IDML 구조 및 스크립트 구문은 검사했지만, 실제 열기·실행·최종 조판은 미검증입니다. 이전 8쪽 v1은 사용자 환경에서 열기 오류가 확인되었고, 이후 Adobe 문서 식별 정보와 기본 구조를 보완했습니다. 실제 INDD 바이너리를 생성했다고 주장하지 않습니다.

## 원문과 편집 구분

- `archive/`: 사용자가 보낸 코드 블록의 원문 11개를 UTF-8로 보관합니다. Unicode 정규화, 맞춤법 교정, 공백 치환을 하지 않았습니다. 각각의 `.txt`, 전체 `.md`, `.json`이 있습니다.
- `archive/SHA256SUMS.txt`: 원문 TXT 11개의 기준 해시입니다.
- `editorial.json`: 별도의 발췌·사용 상황·예문·폰트 분석·인상 초안입니다.
- 지면에는 11개 원문 전체를 반영했습니다. 긴 원문은 지면에서 자동 줄바꿈하며, 보관 파일에는 삽입하지 않습니다. 원문의 일부를 크게 반복한 제목·견본은 원문 전체와 별도 요소입니다.
- 26–27쪽의 12번째 밈은 추가 수집 예정이므로 제보용 지면으로 남겼습니다.

원문은 사용자 메시지와 수동 대조했고 파일 간 동일성과 해시를 검사했습니다. 사용자 메시지 원시 바이트를 직접 추출해 비교한 것은 아닙니다.

## AA와 이모지

A01의 EM SPACE·전각 공백·반각 공백, B02의 U+2800 점자 빈칸과 결합문자, B04의 사람 이모지 순서를 보존했습니다. 기본 한글 서체가 지원하지 않는 글자는 지원 서체로 조판한 뒤 벡터 윤곽으로 배치했습니다. 이 부분은 인쇄 형상을 고정한 파생 디자인이며 글자처럼 수정하는 대신 보존 원문을 복사한 별도 편집본을 기준으로 다시 조판할 수 있습니다. 기본 본문과 해설은 편집 가능한 텍스트입니다.

- A01: Noto Sans Mono CJK KR
- B02 점자: Noto Sans Symbols2
- B02 복합 얼굴: Noto Serif Tibetan + DejaVu Sans Mono, HarfBuzz 결합 조판
- B04 이모지: Noto Emoji 단색, 한글: Noto Sans CJK KR

이 서체 조합에서 원문의 미지원 코드포인트가 없음을 확인했습니다. 원래 표시 기기의 화면과 픽셀 단위로 같은 모양이라는 의미는 아닙니다. 특수 서체의 실제 바이너리는 설치할 필요가 없도록 벡터화했고, 출처·버전·라이선스·코드포인트 확인 결과는 `font_licenses/`에 보관했습니다.

`proofs/`는 A01·B02·B04 인쇄 형상 검수용 이미지입니다. `preview_32p.jpg`와 검수 이미지는 별도 렌더러의 참고 결과이며 InDesign에서 내보낸 것이 아닙니다.

## 인쇄 시

InDesign에서 원본 조판을 확인한 뒤 PDF 내보내기의 **고품질 인쇄**, **재단선**, **문서 도련 설정 사용**을 선택하세요. 펼침면 PDF 제출 여부와 중철 판짜기는 인쇄소 요구에 맞춥니다. 이번 전달물은 사용자의 최신 요청에 따라 InDesign용 파일이며 인쇄용 PDF를 포함하지 않습니다.
