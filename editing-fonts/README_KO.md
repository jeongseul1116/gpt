# 밈 폰트 도감 편집용 폰트

책에 실제 사용한 폰트 중 재배포할 수 있는 **11종**입니다. 이전에 올려주신 **예스체 YES24.ttf**까지 설치하면 전체12종이 갖춰집니다. 예스체 파일은 공개 재배포 조건을 확인하지 못해 이 ZIP에 넣지 않았습니다.

## Windows 설치

1. ZIP을 먼저 압축 해제합니다.
2. Fonts폴더에서 TTF·OTF파일11개를 선택합니다.
3. 마우스 오른쪽 버튼 → ‘설치’ 또는 ‘모든 사용자용으로 설치’를 누릅니다. Windows11에서는 ‘더 많은 옵션 표시’ 안에 있을 수 있습니다.
4. 전에 올려주신 YES24.ttf도 같은 방법으로 설치합니다.
5. InDesign을 완전히 종료한 뒤 다시 실행하고 IDML을 엽니다.

이미 같은 이름의 폰트가 설치되어 있다면, 이 책과 같은 버전을 사용하려는 경우 이 묶음의 파일로 교체합니다. InDesign의 ‘글꼴 찾기/바꾸기’에서 아래 이름을 확인할 수 있습니다.

| 책에서 사용한 이름 | 설치된 패밀리 / 스타일 | 파일 |
|---|---|---|
| Noto Sans CJK KR | Noto Sans CJK KR / Regular | NotoSansCJKkr-Regular.otf |
| Noto Serif CJK KR | Noto Serif CJK KR / Regular | NotoSerifCJKkr-Regular.otf |
| 은궁서 | UnGungseo / Regular | UnGungseo.ttf |
| 주아 (Jua) | Jua / Regular | Jua-Regular.ttf |
| 나눔손글씨 붓 | Nanum Brush Script / Regular | NanumBrushScript-Regular.ttf |
| 둥근모꼴 | DungGeunMo / Normal | DungGeunMo.ttf |
| 블랙 한 산스 | Black Han Sans / Regular | BlackHanSans-Regular.ttf |
| 구기 | Gugi / Regular | Gugi-Regular.ttf |
| 기랑해랑 | Kirang Haerang / Regular | KirangHaerang-Regular.ttf |
| 싱글데이 | Single Day / Regular | SingleDay-Regular.ttf |
| 흑백사진 | Black And White Picture / Regular | BlackAndWhitePicture-Regular.ttf |

은궁서는 Windows에서 ‘은 궁서’로 보일 수 있습니다. 둥근모꼴은 ‘DungGeunMo Normal’ 또는 ‘둥근모꼴 일반체’로 표시될 수 있고, 문서의 스타일 지정은 Normal입니다. 다른 폰트는 Regular입니다.

Noto Sans와 Noto Serif는 책에 사용한 CJK KR Regular를 독립 OTF로 추출했습니다. 다른 Noto Sans KR 버전으로 바꾸지 않았습니다. 글자 형태·문자표·메트릭과 폰트 이름의 일치 여부를 확인했습니다.

Licenses폴더는 폰트별 이용 조건입니다. Sources폴더는 은궁서 GPL-2의 대응 소스·빌드 방법입니다. **설치는 Fonts폴더 안 파일만 하면 됩니다.**

9종은 SIL OFL1.1, 은궁서는 GPL-2, 둥근모꼴은 Public Domain입니다. 폰트 제작자와 저작권·라이선스 표시는 각 원문에 보존했습니다. 폰트 파일을 수정하거나 다시 배포한다면 해당 조건을 확인하세요.

font_manifest.json과 SHA256SUMS.txt에 정확한 이름·버전·파일 해시가 있습니다. 문서 디자인과 내용은 이번 작업에서 변경하지 않았습니다. 실제 Windows 설치와 Adobe InDesign 실행은 이 환경에서 시험하지 않았습니다.
