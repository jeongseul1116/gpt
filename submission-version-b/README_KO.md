## 새 구성

**형태 관찰 → 인상 해석 → 유행어에 적용** 순서입니다. 폰트별64pt 큰 견본과 확대 도해가 먼저 나오고, 유행어는 본문 마지막6쪽에 모았습니다.

| 표지 포함 파일 면 | 내용 |
|---|---|
| 1 | 표지 — ‘말’의 두 골격과 작은 원본 밈 사진 |
| 2–3 | 목차·읽는 방법 |
| 4–15 | 12종 폰트, 한 폰트 한 쪽의 큰 시각화 |
| 16–17 | 같은 포인트의 몸집·진행 폭·잉크 경계 |
| 18–19 | 자간 편집 실험·실제 윤곽 사이의 빈틈 |
| 20 | 편집자의 주관적 인상 지도 |
| 21 | 검은 환기 페이지·응용부 시작 |
| 22–27 | 유행어15개의 기본/선택 폰트 비교 |
| 28 | 뒷표지·출처 |

지면 쪽수는 기존처럼 **목차01부터26**입니다. 위 표는 표지까지 포함한 파일 순서이며, 앞뒤 표지에는 쪽수를 넣지 않았습니다.

## 시각화와 응용

12개 큰 견본은 모두‘진심입니다’64pt입니다. 실제 속공간·국부 획 단면·점 사이 틈·격자·곡선·장식 확대·반전·진행 폭으로 형태를 읽습니다. 측정은 실제 폰트 윤곽에서 얻었습니다. 자간0/+100/−50은 명시한 **편집 실험**이며 내장 커닝값이 아닙니다. 인상 지도는 객관적 성능 점수가 아니라 편집자의 해석입니다.

응용부의15개 사례는 각각 **같은 문구·같은 포인트·같은 색**을 유지하고 기본Noto Sans와 선택 폰트를 비교합니다. 검토한 응답 문구와 대화 앞부분을 그대로 발췌했습니다. 긴 원문과 전체 승인 예문은archive 폴더에 별도로 보존했습니다. 인쇄 지면은 전체 원문 수록본이 아니라 폰트 적용 사례입니다.

폰트12종은 A안과 같습니다. 기존 폰트11종ZIP과 제공하신YES24.ttf를 사용하며 새 폰트 설치는 필요하지 않습니다. 사진은 원본PNG 픽셀과 투명도를 유지해 IDML 안에 포함했습니다. 큰 글자와 도해도 문서 내부의 벡터이며 외부 이미지 링크가 없습니다.

## 인쇄

인쇄용A3 PDF를 **A3가로 / 양면 / 짧은 쪽 넘김 / 실제크기100%**로 출력합니다. **소책자·모아찍기·용지맞춤은 해제**합니다. A3용지7장/PDF14면이며, 각 페이지A5 148×210mm,3mm도련·재단선을 포함합니다. 먼저1–2면을 시험 출력해 방향과100mm확인선을 확인하세요.

표지 포함 인쇄 짝은1–28,2–27입니다. 첫 앞면의 좌우는28｜1, 뒷면은2｜27이며 이후26｜3,4｜25 순서입니다. 재단은 바깥 재단선을 따라 하고 중앙은 접습니다.

A안의37개 파일과 기존 판본 포인터를 해시로 대조해 변경이 없음을 확인했습니다. B안은 별도 파일·폴더와 판본 포인터를 사용합니다. 검수 보고서는qa, 파일 해시는SHA256SUMS.txt에 있습니다.

B안의28면·428개 텍스트·12폰트·15개 응용 사례를 검수했습니다. 모든 텍스트의 실제 잉크 경계까지 확인해 잘림·의도하지 않은 줄바꿈·누락 폰트가 없음을 확인했습니다. 인쇄본도 현재B안의 순서·실치수·도련·재단선과 대조했습니다.

PDF는 IDML을 직접 렌더한 파일입니다. 실제 Adobe InDesign 실행·‘고품질 인쇄’프리셋 내보내기·실물 출력은 이 환경에서 수행하지 못했습니다. PDF의 글자는 윤곽선이며 편집은IDML에서 합니다. [폰트 설치·라이선스 안내](../editing-fonts/README_KO.md)
