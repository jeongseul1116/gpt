# B7 — 아홉 글자, 여덟 간격 전부

비교 문장은 사용자가 정한 **북쪽에계신메리메리**다. 아홉 글자의 모든 인접 간격을 빠짐없이 다룬다. 순서는01북–쪽,02쪽–에,03에–계,04계–신,05신–메,06메–리,07리–메,08메–리다. 같은 ‘메리’가 두 번 나와도06과08을 서로 다른 위치로 따로 표시한다.

12종 폰트 분석의 기준·선택 문장24개에 여덟 간격의 실제 빈틈을 표시한다. 원래32pt 글자 모양과 실제 윤곽의 중앙 정렬을 유지한다. 닫힌 속공간은 분홍, 글자 사이의 빈틈은 주황으로 구분한다. 실제로 닿거나 포개진 구간은 상태를 드러내며 빈 공간을 만들어내지 않는다.

문장 간격 전후 비교는4종 폰트×전후2줄×8간격을 모두 표시한다. 이 책의 편집 조정값도 각 폰트별 여덟 칸에 빠짐없이 적는다. 조정 전후 모두 같은32pt, 같은 글자 윤곽이며 가로 위치만 바꾼다. 조정값은 폰트에 저장된 원래 커닝값이 아니다.

빈틈 도감은 Noto Sans와 은궁서 각각의 모든8쌍을2열×4행으로 배열한다. 전체 문장에서01–08 위치를 먼저 확인하고, 같은36pt 두 글자의 실제 빈틈과 동일 크기로 꺼낸 모양을 나란히 본다. 특정 세 쌍만 발췌하지 않는다.

기존 B급 인상, 표지 오브제 중앙 정렬, 들어가며1쪽, 원문 보존과 승인 유행어15개 적용은 유지한다. A5표지포함28면, A3가로7장/14면·첫28｜1/뒤2｜27·실제100%·3mm도련·재단선도 유지한다. 이전 A/B/B2/B3/B4/B5/B6 파일은 보존한다.
