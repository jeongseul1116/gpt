# 말투수집실 — 28쪽 인디자인 최종 정리본

[편집용 IDML](Maltu_Book_Final_28p.idml?raw=true) · [폰트·이미지 포함 패키지 ZIP](Maltu_Book_Final_Package.zip?raw=true) · [확인용 PDF](Maltu_Book_Final_28p.pdf?raw=true)

한 페이지에 한 주제만 남겼습니다. 시각화 11쪽, 실제 양쪽 섞어짜기 4쪽, 밈 전문 10개를 각각 한 쪽씩 구성했습니다. 표지 포함 28쪽이며 목차가 1쪽입니다. 12폰트 비교는 6종씩 두 쪽으로 나눴고, 글줄 사이·글줄 길이·정렬·단락·쓰기 방향·위계를 각각 별도 페이지로 분리했습니다.

압축을 모두 푼 뒤 IDML을 InDesign에서 열고 ‘다른 이름으로 저장’으로 .indd를 저장하면 됩니다. Document fonts 폴더는 IDML 옆에 그대로 두세요. **예스체 YES24는 기존에 보유한 폰트를 설치해야 합니다.** 공개 재배포 제한으로 이 원본 폰트 파일은 묶지 않았습니다.

사진과 이모지는 문서에 포함되어 있습니다. 일반 글은 텍스트, 분석 도형은 벡터 오브젝트로 편집할 수 있습니다. 문서 구조·28쪽·폰트 해석·줄 넘침·글자 잘림을 파일 기준으로 확인했으며 실제 Adobe InDesign 앱 실행 검사는 하지 않았습니다.
