# B5 — 문장 통째로, 말투는 B급으로

비교 문장은 사용자가 지정한 **북쪽에계신메리메리**다. 띄어쓰기나 철자를 바꾸지 않는다. 한 글자만 떼어 비교하던 방식을 없애고, 아홉 글자가 함께 만드는 리듬과 말투를 본다.

본문 12개 폰트 분석은 같은 32pt 문장으로 진행한다. 기준 폰트 Noto Sans와 선택 폰트의 실제 문장을 같은 크기의 칸에 가로·세로 중앙 정렬한다. 포인트·가로 배율·자간을 폰트별로 조정하지 않는다. 실제 윤곽과 닫힌 빈틈을 선·면으로 표시한다.

종합 비교는 문장의 검은 면 비율, 아홉 글자의 몸집과 사이 틈, 글자 높이와 기준선을 보여준다. 측정값은 32pt 실제 글자 윤곽에서 계산하며 감정 점수가 아니다. 관찰은 형태의 사실을 쓰고 인상은 ‘확성기 풀충전’, ‘편의점 가는데 출정식부터’처럼 편집자의 B급 해석으로 구분한다. 마지막에는 드립을 꺼내기 좋은 상황까지 연결한다.

앞표지는 길거리 광고판의 검정·노랑·빨강·파랑을 유지한다. 제목 두 줄은 같은 60pt이며 각 줄을 중앙에 놓는다. 띠 문구와 통계, 별 안의 문구, 절취선 아래 폰트 이름도 각 영역의 가로·세로 중앙에 맞춘다. 빨간 원은 가운데 정렬된 ‘말’에 붙인다. 뒷표지 사진은 원본을 내부에 내장하고 오른쪽 영역 중앙에 놓는다. 출처와 일반 설명문은 왼쪽 정렬이다.

A5 148×210mm, 표지 포함 28면을 유지한다. 목차에는 쪽수를 표시하지 않고, 들어가며가 1쪽이다. 폰트 분석과 시각화가 먼저 나오고, 실제 유행어 15개 적용은 마지막 6개 본문 페이지에 모은다. 승인된 예문과 원문은 수정하지 않고, 지면의 인상 문구만 별도로 B급 말투로 바꾼다.

인쇄용은 A3 가로 7장/14면, 첫 앞면28｜1·뒷면2｜27 순서다. 실제100%, 짧은 쪽 양면이며 3mm 도련과 재단선을 포함한다. 이전 A·B·B2·B3·B4 파일은 그대로 보존한다.
