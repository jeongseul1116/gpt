# B11 — 목차부터 1쪽 / 펼침면 섞어짜기 / 밈 전문

[전체 36쪽 PDF](Meme_Font_Book_B11_36p.pdf) · [A4 양면 인쇄 PDF](Meme_Font_Book_B11_A4_Duplex.pdf) · [전체 미리보기](B11_All_Pages.png)

목차가 1쪽입니다. 공간 범례는 진행칸·속공간·글자 사이·단어 사이·글줄 사이를 5가지 색과 표식으로 구분합니다. 자간과 단어 간격은 고딕·궁서·도트 각각 3조건에서 비교하고, 행장·정렬·단락 등 사례마다 모양의 변화가 주는 개인적인 인상을 B급 말투로 적었습니다. 관계도와 도감에는 12종 폰트를 모두 복원했습니다.

섞어짜기는 17–18쪽, 19–20쪽의 두 펼침면으로 비교합니다. 왼쪽은 고딕 기준판, 오른쪽은 역할별 혼합 또는 실제 Noto Sans Mono 숫자·문장부호 혼합입니다. 동일한 전체 카톡 대화와 말풍선 크기를 유지했고 숫자 두 곳의 기준선·진행 폭도 비교했습니다. [역할별 비교](B11_Mixed_Spread_17_18.png) · [문자 종류별 비교](B11_Mixed_Spread_19_20.png)

후반 22–34쪽에는 보관된 밈 전문 15개를 해당 폰트로 실었습니다. 긴 ‘인정’ 원문 1,652자는 30–31쪽에 이어집니다. 이전에 검토한 사용 예와 보관 원문은 별도로 표시했고 누락 없이 확인했습니다. 전문을 읽을 수 있는 크기로 넣기 위해 표지 포함 36쪽으로 확장했습니다.

**인쇄: A4 가로 / 실제 크기 100% / 짧은 쪽 양면**, 9장·18면. 이미 소책자 순서이므로 소책자·모아찍기·용지맞춤을 해제합니다. 첫 면은 36｜1, 다음 면은 2｜35입니다. 도련·재단선 없이 종이 정중앙에 접는 선만 있습니다. [인쇄 18면 미리보기](B11_A4_All_18_Faces.jpg)
