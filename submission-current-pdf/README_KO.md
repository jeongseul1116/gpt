# 수정 반영 PDF와 재단선 포함 인쇄용 PDF

**인쇄할 파일: Meme_Font_Book_Revised_A3_Print.pdf**

A3 가로 14장에 A5 펼침면 296×210mm를 실제 크기로 배치했습니다. 재단선, 사방 도련 3mm, 100mm 확인선이 있습니다. 제목 「같은 말, 다른 느낌쓰」와 7쪽 디테일 보정을 반영했습니다.

## 출력 설정

1. 용지 A3, 방향 가로, 단면을 선택합니다.
2. 실제 크기 또는 100%로 출력합니다. 용지 맞춤·자동 축소·소책자·여러 페이지 인쇄는 끕니다.
3. 첫 장의 확인선이 실제 100mm인지 확인한 뒤 나머지를 출력합니다.
4. 바깥 재단선만 따라 자릅니다. 완성 펼침면은 296×210mm이며 가운데는 자르지 않습니다.

출력 순서는 28|1, 2|3, 4|5, …, 26|27입니다. 수업에서 펼침면을 검토하는 순서입니다. 이 디자인의 가장자리는 흰색이므로 외곽 도련도 흰색입니다.

## 파일 구분

- Meme_Font_Book_Revised_A3_Print.pdf: **재단선·3mm 도련 포함 A3 인쇄용**.
- A3_Print_Sheet_04.png: 인쇄용 6–7쪽의 재단선 미리보기.
- Meme_Font_Book_Revised_28p.pdf: 전체 28쪽 **검토용**.
- Meme_Font_Book_Revised_Spreads.pdf: 독서 순서 15개 펼침면 **검토용**.
- Revised_06_07.png: 내용 확인용 6–7쪽 미리보기.

7쪽은 최신 디테일 보정본이고 다른 27쪽은 제목 수정본과 같습니다. 편집 원본은 detail-practice-01/editable의 28쪽 IDML입니다. PDF의 크기·배율·재단선·도련은 검수했으며 실제 프린터 출력은 첫 장에서 확인합니다.
