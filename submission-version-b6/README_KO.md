# B6 — 글자는 그대로, 빈틈이 보이는 비교

[28쪽 PDF](Meme_Font_Book_Version_B6_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B6_28p.idml) · [A3 인쇄 PDF](Meme_Font_Book_Version_B6_A3_Duplex_28p.pdf)

비교 문장은 **북쪽에계신메리메리**입니다. 반복되던 비교 두 펼침면을 다음과 같이 바꿨습니다.

- 지면14–15쪽: 4개 폰트의 같은32pt 문장을 기본 간격과 편집 조정 후로 비교합니다. 글자 모양·크기는 그대로이며 지정된 글자 사이 위치만 바꿨습니다. 주황 면은 실제 마주 보는 획 사이 빈틈이며, 조정값은 이 책의 편집 실험값입니다. 폰트에 저장된 원래 커닝값을 뜻하지 않습니다.
- 지면16–17쪽: 문장 전체20pt에서 ‘쪽에·계신·메리’를 찾아 표시하고, 연결된 두 글자를 같은64pt로 확대해 실제 마주 보는 윤곽과 빈틈을 보여줍니다. 동일한 세 쌍을 Noto Sans와 은궁서에서 비교합니다.

표지·인트로·12종 폰트 분석·나머지 비교 결론·승인 유행어15개 적용과 B급 인상은 B5 그대로입니다. 비교 문장과 표지 문구의 가로·세로 중앙 정렬을 유지합니다. 일반 설명과 출처는 왼쪽 정렬입니다. 사진 원본은 뒷표지에 내부 내장했습니다.

A5 28면, 목차는 무쪽수·들어가며부터1–25쪽입니다. 인쇄는 A3가로7장/14면·짧은 쪽 양면·실제100%입니다. 소책자·모아찍기·용지맞춤을 해제합니다. 첫28｜1·뒤2｜27은 표지 포함 파일 순서입니다. 3mm도련·재단선·100mm확인선을 포함합니다.
