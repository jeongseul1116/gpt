# InDesign 2026용 열기 오류 수정본

[수정 IDML 다운로드](Meme_Font_Book_2026_Open_Fixed.idml)

이번 도입부 수정 과정에서 designmap.xml의 Adobe 파일 식별용 aid 헤더가 빠졌고, 새 Story 참조10개가 본래 Story 참조 구간 뒤로 이동한 것을 확인했습니다. 기존 원본의 식별 헤더를 복원하고,10개 참조를 규격의 Story 구간에 넣었습니다. DOMVersion21.6은 원래 값으로 유지했습니다.

바뀐 ZIP 내부 파일은 designmap.xml 하나입니다. 다른1070개 파일,28면의 본문·디자인·폰트·25개 글자 도해와 내장 표지사진은 동일합니다. 기존PDF의 내용과 인쇄 순서는 변경하지 않았습니다.

## 여는 방법

1. IDML을 다운로드해 컴퓨터에 저장합니다. ZIP을 받았다면 먼저 압축을 풉니다.
2. **InDesign 2026 → 파일 → 열기**에서 `.idml` 파일을 선택합니다.
3. 열리면 **파일 → 다른 이름으로 저장**으로 `.indd` 문서를 저장합니다. 확장자만 `.indd`로 바꾸지 마세요.

표지 이미지는 파일 내부에 들어 있습니다. 폰트12종은 기존 설치 파일11종과 제공하신 YES24.ttf를 사용합니다.

## 페이지 번호

인쇄에 묶이는 짝은 표지 포함 물리적파일순서의 **1–28,2–27**입니다. 실제 첫 장 앞면의 좌우는 **28｜1**, 뒷면은 **2｜27**입니다. 책에 적힌 본문쪽수는 목차부터01이므로, 물리적파일2·27면은 본문01·26으로 보입니다. 표지·뒷표지에는 쪽수를 넣지 않았습니다.
