A5 제출본은28페이지입니다. ZIP에는 같은 내용을 펼침면으로 검토하는15페이지 PDF도 포함했습니다. A3 출력본은 표지28|1과 내부2|3부터26|27까지 총14장입니다. **A3 가로·단면·실제 크기100%**로 출력하고, 첫 장의100mm 기준선을 확인한 뒤 외곽 재단선만 따라 자릅니다. 인쇄소용 중철 판짜기는 아닙니다.

기획안에는 주제·독자·B급 디자인 콘셉트·무드보드·실제 서체 선정 이유·28쪽 차례·출력 계획을 담았습니다. Google Docs 문서 자체는 직접 생성하지 못했으므로, DOCX를 Google Drive에 업로드해 Google 문서로 저장한 뒤 제출해야 합니다.

예스체는 PDF에 내장했고 나머지6서체는 실제 글리프 윤곽으로 출력했습니다. PDF 출력에는 별도 폰트 설치가 필요하지 않습니다. 원문17개는 보관하고, 표정 제외 편집본·발췌는 별도 구분했습니다. 정확한 서체명과 출처는 `font_records/current_fonts/`에 있습니다. 양재샤넬체는 실제 파일이 없어 이번 적용에서 제외했습니다.

파일 규격·7서체·모든 쪽 배치·재단선·도련·원문 보존과 기획안7쪽 렌더를 검수했습니다. 실제 종이 출력과 Google Docs 변환·공유 설정은 사용자가 확인해야 합니다. 편집용 IDML/JSX는 구조·구문 검수만 했으며 실제 InDesign 실행은 미검증입니다.
