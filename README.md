# 마참내! 폰트도 웃길 수 있다

정슬기 기획안을 바탕으로 제작한 A5 밈 타이포그래피 소책자 디자인 초안입니다.

- 문서: A5 148×210mm, 8쪽, 4개 펼침면, 문서 도련 3mm
- 구성: 말보다 표정 / 일단 가보자고 / 사랑이 너무 많아 / 폰트 실험실
- 전체 32쪽 기획 중 발췌 시안이며, 페이지 번호는 04–11입니다.
- 무료 한글 고딕·명조 계열 서체인 Noto Sans CJK KR와 Noto Serif CJK KR의 Regular·Bold를 사용합니다.

## 파일

- [InDesign 편집용 IDML](design/Meme_Typography_8p.idml): InDesign에서 편집할 수 있도록 작성한 IDML 문서
- [전체 미리보기](design/preview.jpg): 별도 렌더러로 생성한 레이아웃 참고 이미지

## 열기

서체를 설치한 뒤 IDML을 InDesign에서 엽니다. 서체 대체·문자 기호·텍스트 넘침·펼침면을 확인하고 `.indd`로 저장하세요.

서체 공식 배포: https://github.com/notofonts/noto-cjk

## 검증과 제한

ZIP 무결성, XML 구문, 8개 페이지와 86개 텍스트 스토리의 참조를 검사했습니다.
InDesign 실행 환경이 없어 실제 열기와 조판은 검증하지 못했습니다. 이 파일은 `.indd`가 아닙니다.
별도 폰트 분석 리포트나 실제 밈 이미지는 제공되지 않아, 새 원고와 문자 표정을 사용했습니다.
미리보기는 InDesign에서 내보낸 결과가 아닙니다.
