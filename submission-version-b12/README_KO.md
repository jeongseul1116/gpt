# B12 — 표지 포함 28쪽

표지 포함 총 28쪽이며 목차가 1쪽입니다. 비교 문장은 ‘북쪽에 계신 아름다운 메리메리 리얼 카인드니스 여러분’입니다. 획·끝 모양·글자 틀·간격이 다른 12종을 선정했습니다. 공간은 진행칸·속공간·글자 사이·단어 사이·글줄 사이를 서로 다른 5색과 표식으로 구분합니다. 자간과 단어 사이 비교에는 고딕·궁서·도트 각각 3조건을 적용했고, 조판 변화에서 생기는 인상을 B급 말투로 연결했습니다.

**섞어짜기 11–12쪽과 13–14쪽은 양쪽 모두 실제 혼합 조합입니다.** 동일한 전체 카톡 대화와 말풍선 크기를 유지합니다. 첫 펼침면은 명조+굵은 답장과 궁서+둥근 답장을, 다음 펼침면은 한글 고딕에 명조 숫자·문장부호를 섞은 안과 실제 고정폭 Noto Sans Mono를 섞은 안을 비교합니다. ‘과대’로 수정했고 고백 전문과 이모지를 보존했습니다. [역할 조합 펼침면](B12_Mixed_Spread_11_12.png) · [문자 종류 조합 펼침면](B12_Mixed_Spread_13_14.png)

후반 15–26쪽은 보관된 밈 15개의 전문을 해당 폰트로 보여줍니다. 긴 E09의 1,652자는 22–23쪽에 11pt로 이어집니다. 사용 예와 보관 전문은 따로 표시했습니다.

**인쇄: A4 가로 / 실제 크기 100% / 짧은 쪽 양면**, 7장·14면입니다. 소책자·모아찍기·용지맞춤을 해제합니다. 이미 소책자 순서이며 첫 면은 28｜1, 다음 면은 2｜27입니다. 도련과 재단선은 없고 종이 정중앙에 접는 선만 있습니다. [인쇄 14면 미리보기](B12_A4_All_14_Faces.jpg)
