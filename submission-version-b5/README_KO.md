# B5 — 문장 통째로, 말투는 B급으로

[28쪽 PDF](Meme_Font_Book_Version_B5_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B5_28p.idml) · [A3 인쇄 PDF](Meme_Font_Book_Version_B5_A3_Duplex_28p.pdf)

비교 문장은 **북쪽에계신메리메리**로 통일했습니다. 한 글자를 떼어 놓던 비교를 없애고, 실제 아홉 글자 문장을 같은 32pt로 비교합니다. 마지막 두 폰트씩 고르는 페이지는 같은 문장을 16pt로 비교합니다. 각 비교 문장은 실제 보이는 윤곽 기준으로 칸의 가로·세로 중앙에 놓았습니다. 폰트별로 글자를 늘리거나 줄이지 않습니다.

실제 윤곽·닫힌 빈틈·검은 면 비율·아홉 글자의 몸집과 사이 틈을 보여줍니다. 비율은 32pt 글자 모양의 실제 합집합 면적÷(문장 진행 폭×48pt)이며, 모든 폰트가 같은 0–40% 축을 씁니다. 감정 점수가 아닙니다. ‘확성기 풀충전’, ‘편의점 가는데 출정식’ 같은 인상은 편집자의 B급 해석으로 따로 표시했습니다. 실제 유행어 적용 15개의 승인 문구는 그대로이며, 인상 문구만 바꿨습니다.

표지 두 제목은 같은 60pt를 유지하고 중앙 정렬했습니다. 띠 문구·통계·별 안의 글자·절취선 아래 폰트 이름도 각 영역의 가로·세로 중앙에 맞췄습니다. 뒷표지 사진은 원본을 내장하고 오른쪽 영역 중앙에 놓았습니다. 일반 설명과 출처는 왼쪽 정렬입니다.

A5 28면, 목차는 무쪽수이며 들어가며부터 1–25쪽입니다. A3 가로 7장/14면·짧은 쪽 양면·실제 100%로 인쇄합니다. 소책자/모아찍기/용지 맞춤은 해제합니다. 첫 28｜1, 뒤 2｜27은 표지 포함 파일 순서입니다. 3mm 도련·재단선·100mm 확인선을 포함합니다.

IDML은 편집 가능한 텍스트·실제 폰트 벡터·내장 사진을 사용합니다. 기존 폰트 11종과 제공된 YES24.ttf를 사용합니다. [폰트 설치](../editing-fonts/README_KO.md)

PDF는 IDML 직접 렌더본이며 실제 Adobe 실행·프리셋 내보내기·실물 출력은 미검증입니다. qa는 측정·정렬·내용·구조·인쇄 검수 보고서, archive는 원문과 승인 예문 및 별도로 편집한 인상 문구입니다. 파일 해시는 SHA256SUMS.txt입니다.
