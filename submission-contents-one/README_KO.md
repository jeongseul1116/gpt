# 목차부터 1쪽

총 제작 분량은 표지·뒷표지를 포함해 A5 28면입니다. 앞표지와 뒷표지는 번호를 표시하지 않고 **목차를01쪽으로 시작해 본문26쪽까지** 매깁니다. PDF의 두 번째 물리 페이지가 목차01쪽입니다. PDF 뷰어의 페이지 라벨도 표지 /1–26 /뒤표지로 맞췄습니다.

목차 안의 모든 페이지 안내와 마지막 한마디 안내도 수정했습니다. 출처가 실린 뒷표지는 목차에 ‘뒤표지’라고 표시합니다. 실제 좌우 배치를 유지하므로 인쇄된 홀수 쪽수가 왼쪽, 짝수 쪽수가 오른쪽에 옵니다. 28면의 독서 순서와 중철 면조립은 그대로입니다.

이전에 삭제한 반복 상단 책 이름·라벨 오른쪽 문구·하단 책 이름과 이름은 계속 생략합니다. 표지의 제목 두 줄은 같은 예스체34pt·검정·행간42pt이고, 복원한 타원 사진은874×1275px·300dpi입니다. 12폰트·15밈·126비교견본·21글자도해·TF분석을 유지했습니다.

## 양면 인쇄

**PDF/Meme_Font_Book_System_A3_Duplex_Booklet.pdf**를 사용합니다. PDF14면은 앞·뒷면이 교대로 들어 있는 A3용지7장입니다.

- A3 가로·양면·짧은 쪽 넘김·실제 크기100%.
- 소책자·모아찍기·용지 맞춤·자동 축소를 끕니다. 이미 중철 순서입니다.
- PDF1–2면을 먼저 시험 출력해 위아래 방향과100mm기준선을 확인합니다.
- 외곽 재단선만 자르고 가운데는 자르지 않습니다. 1번장을 바깥에,7번장을 안쪽에 넣어 가운데를 접습니다.

아래 번호는 물리 PDF순서가 아닌 **책에 인쇄된 쪽수**입니다.

| 종이 | 앞면 왼쪽 / 오른쪽 | 뒷면 왼쪽 / 오른쪽 |
|---|---|---|
| 1 | 뒤표지 / 표지 | 01 / 26 |
| 2 | 25 / 02 | 03 / 24 |
| 3 | 23 / 04 | 05 / 22 |
| 4 | 21 / 06 | 07 / 20 |
| 5 | 19 / 08 | 09 / 18 |
| 6 | 17 / 10 | 11 / 16 |
| 7 | 15 / 12 | 13 / 14 |

완성 한 쪽148×210mm, 펼침면296×210mm입니다. 재단선·실제3mm도련·100%배치·짧은 쪽 양면 설정을 검사했습니다. 본문26면 색탭은 도련까지 이어지고 표지의 도련은 흰색입니다. 실물 프린터 출력은 미검증입니다.

## 파일

- Contents_Preview.png: 인쇄 쪽수01인 목차.
- PDF/Meme_Font_Book_System_28p_Review.pdf: A5 전체28면, 목차 링크·북마크 각16개, 페이지 라벨은 표지/1–26/뒤표지.
- PDF/Meme_Font_Book_System_Spreads_Review.pdf: 독서 순서15펼침면 검토용.
- editable/Meme_Font_Book_System_28p.idml: InDesign 편집 파일. Links폴더와 함께 둡니다.
- editable/Create_System_28p.jsx: INDD와 독서 순서 펼침면 PDF를 만드는 스크립트. 중철 출력은 위A3면조립PDF를 사용합니다.
- Planning_28p_GoogleDocs.docx: 새 쪽수 체계와 최신 지면·무드보드를 반영한8쪽 기획안.
- photoshop/Cover_Oval_Restored.psd: 흰 배경·원본 사진·타원 복원 부분을 분리한3레이어PSD. Adobe Photoshop은 이 환경에 없어 실제 실행하지 않았고, ImageMagick으로 수동 복원해 PSD 구조와 합성을 검증했습니다.
- photoshop/Original_Source.png: 변경하지 않은 사진 원본.

폰트 원본은 동봉하지 않았습니다. font_records에 정확한 이름·출처·라이선스가 있습니다. 수집 원문은 변경하지 않았으며 AA·표정 이모티콘 보관 파일은 ZIP에 없습니다.

IDML·JSX는 구조·내용·좌표·폰트·쪽수·도련을 정적으로 검수했습니다. 실제 Adobe InDesign 실행·내보내기는 미검증입니다.
