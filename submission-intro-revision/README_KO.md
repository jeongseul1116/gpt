# 밈 폰트 도감 인트로 수정본 28쪽

2–3쪽을 반표제·헌정과 서문으로 다시 구성했습니다. 2쪽은 받는 사람 이름을 적는 자리, 3쪽은 책의 취지와 즐기는 방식을 담은 네 문단 서문입니다. 짧은 밈 모음은 27쪽 본문 후반으로 옮겼습니다.

4–5쪽의 일곱 서체 도감과 6–25쪽 본문은 유지했습니다. 난 오늘만 산다는 26쪽 한 면에 원문과 세 서체 비교를 함께 담아 총28쪽을 맞췄습니다. AA 얼굴·군중 이모지·문자표정은 현재 PDF·편집 원본·미리보기에 사용하지 않았습니다.

## 현재 제출 파일

- PDF/Meme_Font_Book_28p_Intro_Revision.pdf: A5 28쪽 전체 디자인.
- PDF/Meme_Font_Book_28p_Intro_Spreads.pdf: 같은 28쪽을 독서 순서의15개 펼침면으로 보는 검토본.
- PDF/Meme_Font_Book_28p_Intro_A3_Print.pdf: A3 가로14장, A5 펼침면 실제 크기, 도련3mm와 재단선 포함.
- editable/Meme_Font_Book_Intro_Revision_28p.idml: 현재 지면의 InDesign 편집 파일.
- editable/Create_Intro_Revision_28p.jsx: InDesign 안에서 새 INDD를 만드는 스크립트.
- Planning_Intro_Revision_GoogleDocs.docx: 현재 구성을 반영한7쪽 기획안.

Opening_02_03.png는 수정한 인트로, Closing_Memes_26_27.png는 후반으로 옮긴 짧은 밈 지면입니다. 모든 미리보기는 현재 PDF에서 새로 렌더했습니다.

## 인디자인 편집

ZIP을 풀고 IDML 또는 JSX와 같은 위치의 Links 폴더를 유지하세요. 실제 InDesign 열기·실행은 검증하지 못했으며 문서 구조·내용·폰트·좌표와 JSX 문법을 정적 검수했습니다.

필요한 서체는 YES24 Regular, Noto Sans CJK KR Regular, Noto Serif CJK KR Regular, UnGungseo Regular, Jua Regular, Nanum Brush Script Regular, DungGeunMo Normal입니다. 정확한 서체 정보와 라이선스는 font_records에 있습니다. 폰트 원본은 동봉하지 않았습니다. PDF는 별도 폰트 설치 없이 열 수 있습니다.

## 기획안과 출력

기획안은 Google Drive에 올려 Google 문서로 연 다음 Google 문서로 저장해 제출할 수 있습니다. Google Docs 문서 자체를 직접 생성하거나 공유 설정을 변경하지는 않았습니다.

출력은 PRINT_GUIDE_KO.md에 따라 A3 가로·단면·실제 크기100%로 설정합니다. 첫 장의100mm 기준선을 확인하고 바깥 재단선만 따라 자릅니다. 실제 프린터 출력은 별도로 확인해야 합니다.

원문17개와 보존 파일은 프로젝트의 기존 보관 위치에 그대로 두었습니다. 이번 ZIP에는 현재 제출 파일과 편집 지면 데이터만 담았습니다. 표정이 포함된 보관 원문이나 이전 시안 이미지는 이 묶음에 넣지 않았습니다. 표정 제외 편집본의 구분은 display_editions.json에 기록했습니다.
