# 마참내! 폰트도 웃길 수 있다

친구들에게 나눠줄 병맛 밈 폰트 도감. 정슬기 기획과 사용자 제공 원문 11개를 바탕으로 작성한 **A5 세로·중철·32쪽 디자인 초안**입니다.

- [32쪽 InDesign 편집용 IDML 다운로드](https://github.com/jeongseul1116/gpt/raw/refs/heads/main/book-32p/Meme_Typography_32p.idml)
- [전체 패키지 다운로드](https://github.com/jeongseul1116/gpt/raw/refs/heads/main/Meme_Typography_32p_package.zip)
- [32쪽 미리보기](book-32p/preview_32p.jpg)
- [원문 보존 아카이브](book-32p/archive/memes_original.md)
- [사용 방법과 검증 범위](book-32p/README_KO.md)

원문은 줄바꿈·공백·이모지를 별도 보존하고, 편집용 발췌·상황·예문·폰트 분석을 분리했습니다. 지면에는 11개 원문 전체를 반영했습니다. 12번째 밈의 26–27쪽은 추가 수집을 위한 제보 지면입니다.

32쪽은 표지·뒷표지 각 1쪽과 본문 15개 펼침면으로 구성되며, 문서 도련은 사방 3mm입니다. AA·이모지는 지원 서체로 조판한 벡터 파생본이며, 본문과 해설은 편집 가능한 텍스트입니다. 실제 폰트명과 라이선스 기록을 동봉했습니다.

**InDesign 실행 환경이 없어 실제 열기·조판은 미검증입니다.** ZIP·XML·객체 참조, 원문 보존 파일과 지면 데이터 일치, 별도 렌더러의 미리보기는 검사했습니다. IDML 열기가 실패하면 [InDesign 내부에서 새 INDD를 만드는 JSX](book-32p/Create_32p_InDesign.jsx)를 스크립트 패널에서 실행하는 대체 방법이 있습니다. INDD 바이너리를 직접 생성했다고 주장하지 않습니다.

이전 8쪽 시안과 보완 파일은 `design/`에 보관했습니다. 최신 작업은 `book-32p/`입니다.
