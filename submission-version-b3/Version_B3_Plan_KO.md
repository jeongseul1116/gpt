# B3 — 말투 접수 광고판

B2의 같은 문구·같은 크기·같은 부위 비교를 유지하고, 길거리 광고 전단의 색과 배치로 책의 B급 인상을 강화했다. 앞표지는 검정 광고판·노란 큰 글씨·빨간 원·파란 통계 띠, 하단은 뜯어가는 폰트표다. 제목 ‘밈 폰트 도감 / 말투수집실’은 두 행을 같은 크기로 두며 ‘마참내! 폰트도 웃길 수 있다’는 부제목이다. 기존 ‘무섭다’ 사진은 뒷표지에 원본 그대로 내부에 포함한다.

## 구성과 번호

A5 세로148×210mm, 표지 포함28면, 중철 기준. 앞표지·목차·뒷표지에는 쪽수를 찍지 않는다. 물리3면 ‘들어가며’부터지면1쪽, 물리27면까지25쪽이다. InDesign Section과 PDF PageLabels도 이 기준으로 맞춘다.

## 시각화와 리듬

관찰12쪽의 ‘진심입니다’64pt, 확대 ‘심’128pt, 원점·기준선·격자·실제 속공간과 윤곽 경계는 B2와 같다. 펼침면별 대조 제목, 접수번호, 검정/노랑 소제목이 읽는 리듬을 만든다. 감정의 해석은 편집자의 주관임을 구분한다.

응용부는2사례 쪽에서 같은 기준선의 좌우 접수표,3사례 쪽에서 위아래 광고3단으로 배치한다. 같은 사례 안의 문구·포인트·색은 같고 폰트만 달라진다. 승인한 응답·대화·인상 문구는 그대로 유지한다. 원문은 별도 archive에 보존한다.

## 출력

A3 가로7장·14면, 실제크기100%, 양면 짧은 쪽 넘김. 표지 포함 파일 순서를 조판하므로 첫 앞면28｜1, 뒷면2｜27이다. 지면의1쪽인 들어가며는 파일3면이므로 인쇄 짝 계산과 구분한다. 각A5는3mm도련과 재단선 포함. 소책자·모아찍기·용지맞춤을 해제하고 먼저 앞뒤1장을 시험 출력한다.

IDML에는 살아 있는 텍스트·폰트의 실제 윤곽 벡터·내장 사진을 사용한다. 실제Adobe실행·고품질 인쇄 프리셋 내보내기·실물 출력은 미검증이며 PDF는 IDML직접렌더본이다. 기존 A·B·B2는 별도 파일로 보존한다.
