# TF 시각화와 폰트 느낌의 원인 보완

첨부하신 「수정파일.indd」를 읽어 만든 IDML을 기준으로 작업했습니다. 사용자 수정본의 표지·목차·흰 비교 카드와 분홍 머리띠·원고·폰트 견본·쪽수를 유지하고, 폰트 느낌을 설명하는 문장과 실제 글자 도해를 보완했습니다. 원본 INDD 파일은 변경하지 않았습니다.

## 반영한 내용

- 108개 비교 카드: 먼저 ‘형태’를 읽고, 화살표 뒤에서 그 형태가 내게 어떤 말투로 읽히는지 보도록 바꿨습니다.
- 짧은 말 18개 견본에도 형태와 인상을 짝지었습니다. 비교 문구126개와 폰트 지정·크기는 그대로입니다.
- 폰트 도감12종: 관찰 가능한 형태와 개인적 인상을 연결해 설명했습니다.
- 글자 도해21개: 실제 폰트 윤곽을 사용해 획·분리된 점·하트·계단형 끝을 색으로 짚었습니다. 블랙 한 산스의 ‘마’는 ㅁ의 좁은 속공간을 분홍으로, 실제 세로획의 두께를 빨간 선으로 표시합니다.
- 밈의 설명: 글자의 형태에서 읽히는 말투가 해당 상황에서 왜 웃긴지 연결했습니다.

구기의 원형 점이나 싱글데이의 하트는 폰트 파일에 실제로 들어 있는 모양입니다. 새로운 이모지를 얹지 않았습니다. 느낌은 이 책의 문구와 상황을 보며 쓴 개인적 해석입니다. 확인하지 못한 TF 수업 내용이나 이전 분석 리포트를 인용하지 않았습니다.

## 파일

- TF_Visual_Analysis_28p.idml: 수정 내용을 반영한 InDesign 편집본. 표지 사진은 파일 내부에 들어 있으며 도해도 내부 벡터라 별도 Links폴더가 필요하지 않습니다.
- TF_Visual_Analysis_28p_Proof.pdf: A5 전체28면 검토용 PDF. InDesign의 실제 PDF 내보내기가 아니며 최종 인쇄용 인증본이 아닙니다.
- Font_Analysis_03_04.jpg: 인쇄쪽수03–04의 폰트 도감 펼침면.
- TF_Anatomy_Detail.png: 실제 글자 부위와 설명을 확대한 미리보기.
- Comparison_06_Preview.png: 인쇄쪽수06의 형태→말투 비교 카드.
- Short_Memes_26_Preview.png: 짧은 말의 형태→인상 예시.

기존에 제공한 폰트11종과 YES24.ttf를 설치한 뒤 IDML을 InDesign에서 열고 INDD로 저장할 수 있습니다.

## 확인한 범위

INDD 구조를 읽는 오픈소스 변환기를 사용했으며 Adobe InDesign을 직접 실행하지 않았습니다. 변환기에서 경고는 없었지만 Adobe의 모든 설정을 완전히 재현한다고 보증할 수 없습니다. 편집본은 첨부 INDD에서 변환한 내용에 한정해 수정했습니다.

수정 전후 파일을 대조해 표지 이미지·126개 원문 견본·그 밖의 텍스트·페이지와 기존 프레임 좌표·폰트·색·스타일이 보존되는지 검사했습니다. 새 도해는 실제 폰트 윤곽과 대조했고, 검토PDF의 모든28면과 주요 설명면을 확인했습니다. 새 설명의 계측상 넘침·누락 글자는 없습니다.

검토PDF의 첫 기준선과 자동 줄바꿈은 Adobe와 다를 수 있습니다. 기존 원고 중7개 프레임에는 검토용 자동 줄바꿈을 적용했습니다. 실제 InDesign 열기·저장·글자 넘침과 최종 출력은 이 환경에서 검증하지 못했습니다. 인쇄 제출 전에는 InDesign에서 최종 상태를 확인해 고품질 인쇄·재단선·문서 도련 설정으로 내보내면 됩니다.
