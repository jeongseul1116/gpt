# 말투수집실 — 시각화 중심 B안

기존 A안은 별도 파일로 보존하고 새 판을 만든다. 새 판의 읽기 순서는 **형태 관찰 → 인상 해석 → 유행어에 적용**이다. 폰트의 특징을 먼저 시각적으로 이해한 뒤, 마지막에서야 그 폰트가 유행어를 어떻게 돋보이게 하는지 확인한다.

## 주제와 목적

12종의 한글 폰트를 굵기·속공간·폭·간격·획 끝·장식·격자로 관찰한다. 같은 문장과 같은 포인트를 사용해 폰트의 형태 차이를 읽고, 각 형태가 편집자에게 어떤 목소리로 느껴지는지 구체적으로 설명한다. 응용부에서는 검토한 유행어15개를 같은 크기와 색으로 두 번 보여준다. 기본 폰트와 선택 폰트의 효과를 비교하고 상황에 맞는 폰트를 고르게 하는 책이다.

## 디자인 콘셉트

큰 견본과 부분 확대가 지면의 중심이다. 흰 바탕, 검정 글자, 주홍색 측정선과 옅은 분홍 면을 사용한다. 설명은 짧게 두고 실제 윤곽·빈틈·경계선·격자·진행 폭으로 차이를 보여준다. 책 앞부분은 관찰 노트의 질서, 마지막 응용부는 B급 유행어의 과장된 말투를 담는다.

표지는 큰 ‘말’의 두 골격을 겹쳐 보여주고, 요청한 원본 밈 사진을 작게 배치한다. 사진의 빨간 타원은 온전히 보이도록 한다. 앞표지와 뒷표지에는 쪽수를 표시하지 않는다.

## 폰트

블랙 한 산스, Noto Sans CJK KR, Noto Serif CJK KR, 은궁서, 구기, 둥근모꼴, 주아, 싱글데이, 기랑해랑, 흑백사진, 나눔손글씨 붓, 예스체 YES24. 기존 설치 파일과 라이선스 범위를 사용한다. 실제 제공되지 않은 굵기나 유료 폰트를 전제하지 않는다.

## 차례와 페이지 구성

아래 숫자는 표지를 포함한 파일 순서다. 지면 쪽수는 목차부터01로 시작한다.

| 파일 면 | 내용 | 표현 방법 |
|---|---|---|
| 1 | 앞표지 | ‘말’의 골격 중첩과 작은 밈 사진 |
| 2 | 목차 | 관찰·비교·응용의 순서 |
| 3 | 읽는 방법 | 관찰→해석→적용의 세 단계 |
| 4–15 | 12폰트 관찰 | 한 폰트 한 쪽, 공통64pt 견본과 큰 구조 도해 |
| 16–17 | 같은 크기, 다른 몸집 | 진행 폭·잉크 경계·글자칸 비교 |
| 18–19 | 간격 실험 | 자간 편집과 실제 윤곽 사이의 빈틈 구분 |
| 20 | 인상 지도 | 편집자의 주관적 말투 분류 |
| 21 | 응용부 시작 | 검은 환기 페이지 |
| 22–27 | 유행어15개 응용 | 같은 문구·크기·색, 기본/선택 폰트 비교 |
| 28 | 뒷표지·출처 | 사용 폰트·이미지·원문 설명 |

## 원고 원칙

확정된 대화와 응답은 유지한다. 응용부는 승인 예문의 응답 문구와 대화 앞부분을 발췌해 배치하며, 긴 원문 전체와 승인 예문은 별도 파일에 보존한다. 기존 상황 설명을 고쳐 의미를 바꾸지 않는다. 측정값은 실제 윤곽에서 얻고, 편집 실험의 자간값과 폰트 내장 커닝값을 구분한다. 인상 지도는 객관적 성능 점수가 아니라 편집자의 해석임을 밝힌다.

## 판형과 출력

A5세로148×210mm, 표지 포함28쪽, 중철 기준. 좌우36pt의 대칭 여백을 사용한다. A3가로7장 양면 인쇄용PDF를 별도로 만들고3mm도련과 재단선을 포함한다. 인쇄 순서는 첫 앞면28｜1, 뒷면2｜27이며 실제 크기100%·짧은 쪽 넘김을 사용한다.
