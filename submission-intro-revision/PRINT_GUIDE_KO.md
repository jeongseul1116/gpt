# 수업에 가져갈 출력물

인쇄할 파일은 **PDF/Meme_Font_Book_28p_Intro_A3_Print.pdf**입니다. A3 14장에 전체 28쪽이 들어 있습니다.

1. Adobe Acrobat Reader에서 파일을 엽니다.
2. 용지는 **A3**, 방향은 **가로**, 인쇄는 **단면**으로 선택합니다.
3. 크기 조정은 **실제 크기 또는 100%**로 선택합니다. 용지에 맞추기·큰 페이지 축소·자동 확대·소책자·한 장에 여러 페이지는 끕니다.
4. 우선 PDF 1장만 시험 출력합니다. 아래 100mm 기준선을 자로 재어 실제 100mm인지 확인합니다.
5. 배율이 맞으면 PDF 2–14장을 추가로 출력합니다. 맞지 않으면 프린터 배율을 바로잡고 다시 확인합니다.
6. 바깥쪽 재단선 4개 모서리를 연결해 자릅니다. 완성된 펼침면은 **296×210mm**입니다. 가운데는 자르지 않습니다.
7. 출력·재단한 14장을 순서대로 가져갑니다. 제본은 이번 과제에서 선택입니다.

책 한 쪽은 148×210mm이며, 펼침면은 296×210mm입니다. 표준 A4 가로폭 297mm와 1mm 다르므로 A4에 맞춰 다시 확대하지 마세요. PDF에는 사방 도련 3mm와 바깥 재단선을 넣었습니다. 이 디자인의 재단 가장자리는 흰색이므로 바깥 도련도 흰색입니다.

출력 순서는 표지 28|1, 내부2|3,4|5,…,26|27입니다. 이는 수업에서 펼침면을 검토하는 순서이며, 중철 제본용 인쇄소 판짜기나 양면7장 소책자 출력 파일은 아닙니다.

PDF 용지크기·콘텐츠 배율·도련·재단선·100mm 기준선·글꼴 처리를 검사했습니다. 실제 프린터의 설정과 종이 출력 결과는 첫 장 시험 출력으로 확인하세요.
