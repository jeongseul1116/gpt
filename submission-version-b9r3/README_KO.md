# B9r3 — A4 양면·접는 선만

표지 하단 네 칸을 같은 구조의 ‘말투 뜯어가기’로 정리했습니다. 분류명은 같은 폰트·크기로 맞추고, 아래에는 같은 전체 문장을 네 폰트의 같은 14pt로 보여줍니다. 안내문은 칸 위에 놓았습니다. 뒷표지 사진을 파란 띠에 붙인 수정은 유지했습니다.

**인쇄: A4 가로 / 실제 크기 100% / 짧은 쪽 양면.** 총 7장·14면입니다. 도련·재단선·출력 눈금·용지 바깥 안내문을 제거하고 종이 정중앙에 얇은 회색 접는 선만 넣었습니다. 파일 자체가 소책자 순서로 배치되어 있으므로 소책자·모아찍기·용지맞춤은 해제합니다. 첫 면은 28｜1, 다음 면은 2｜27입니다. A5 두 페이지를 100%로 가운데 놓아 A4 종이의 바깥 양끝에 각각 0.5mm 여백이 남습니다.

본문의 폰트·문구·배치는 유지했으며, 도련 제거에 맞춰 페이지 바깥의 검정 배경 연장을 정리했습니다. 편집 원본도 도련 0mm·재단선 해제로 갱신했습니다. PDF를 파일 기준으로 검증했으며 실제 Adobe 실행과 실물 출력은 검증하지 않았습니다.
