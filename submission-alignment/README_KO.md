## 바꾼 내용

**‘가만히’ 추가 견본21개를 제거했습니다.** 대조표의 기존 ‘진심입니다’12개를 한 번씩만 사용하고, 해당 문장 안에 폰트 특징을 표시합니다. 인트로 비교는 같은 단어 ‘진심’으로 통일했습니다.

폰트마다 관찰할 부분에 맞춰 시각화했습니다.

- 블랙 한 산스: 실제 ‘심’의 속공간을 분홍 면으로 표시하고 세로획을 측정합니다.
- 구기: 실제 원형 점과 획 사이의 틈을 표시합니다. 커닝값으로 부르지 않습니다.
- 기랑해랑: 글자칸 중심의 기준축으로 고르지 않은 골격을 읽습니다.
- 싱글데이: 실제 하트 장식을 표시하고 부분 확대합니다.
- 흑백사진: 실제 윤곽과 패인 가장자리를 강조합니다.
- 둥근모꼴: 실제1/16em 단위 격자를 겹쳐 계단 윤곽을 보여줍니다.
- 은궁서: 실제 글자 진행 칸을 면과 경계선으로 표시합니다.
- 주아: 실제 둥근 획과 모서리를 관찰합니다.
- 나눔손글씨 붓: 글자별 실제 잉크 경계와 기준선으로 몸집·폭의 차이를 보여줍니다.
- 예스체: 미세하게 둥근 모서리를 임의의 직각으로 표시하지 않고, 실제 곧은 획을 표시합니다.
- Noto Sans·Serif: 실제 ‘니’의 국부 획 단면을 같은 방식으로 측정합니다. 이 값은 해당 부위의 측정값이며 폰트 전체 굵기나 커닝값이 아닙니다.

인트로에서는 같은56pt ‘진심’의 ㅁ 세로획과 속공간을 비교합니다. 아래48pt 비교는 글자칸·초성/중성/받침 경계·글자 사이 빈틈을 보여줍니다. 참고 이미지의 숫자나 폰트를 복사하지 않고 책에 실제 사용한 폰트의 윤곽에서 도출했습니다.

## 정렬 수정

본문 하단9곳의 중복 단어 도해를 없애고, 설명36개 프레임을 본문 왼쪽 기준선39.685pt에 맞췄습니다. 뒷표지는 페이지 방향에 따라 안팎 여백이 바뀌어 보이지 않도록 좌우14mm를 명시하고 모든 요소를 그 안에 정렬했습니다.

대조표의 ‘진심입니다’는 편집 가능한 텍스트입니다. 12개 모두18pt이고, InDesign의 고정 첫 기준선18pt를 지정해 분석 그래픽과 기준선을 공유합니다. 도해는 문서 내부의 편집 가능한 벡터입니다. 표지 PNG도 내부에 포함됩니다.

## 유지한 내용

총28면, 목차01쪽 시작, 표지·뒷표지 쪽수 없음,12종 폰트, 본문 비교 견본126개를 유지했습니다. 대조표의 기존 문장12개도 그대로입니다. [검토해주신 예문15개](Approved_Examples_15.md)의23개 텍스트 블록은 직전 승인본과 바이트 단위로 동일합니다. 앞표지 사진·제목 크기와 나머지 수정 사항도 유지했습니다.

## 인쇄

인쇄용A3 PDF는 **A3가로 / 양면 / 짧은 쪽 넘김 / 실제크기100%**로 출력합니다. **소책자·모아찍기·용지맞춤은 끕니다.** 표지 포함1–28,2–27 짝으로 이미 배치한 파일입니다. 첫 앞면은28｜1, 뒷면은2｜27입니다. 목차부터 시작하는 본문번호와 표지 포함 파일번호는 다릅니다.

A3용지7장/PDF14면, 각 페이지A5 148×210mm,3mm도련과재단선을 포함합니다. 먼저1–2면을 양면 시험 출력해 방향과100mm확인선을 확인한 뒤 출력하세요. 바깥 재단선을 따라 자르고 중앙은 접습니다.

## 확인 범위

식별 헤더·참조 순서·고정 기준선·실제 폰트 윤곽·주석의 지면 안 배치·하단9곳·대칭 뒷표지 여백을 검수했습니다. 현재PDF를 확대해 겹침·잘림을 확인했고, 현재 인쇄 파일의28면 접지 순서·실치수·도련·재단선·접는 선 안쪽 내용을 대조했습니다. 검수 보고서는qa, 파일 해시는SHA256SUMS.txt에 있습니다.

PDF는 IDML을 직접 렌더해 제작했습니다. 실제 Adobe InDesign 실행·‘고품질 인쇄’프리셋 내보내기·실물 출력은 이 환경에서 수행하지 못했습니다. 기존6개 프레임은 근사 줄바꿈으로 렌더되며 이전과 동일합니다. PDF 글자는 윤곽선이고 편집은IDML에서 합니다. 원본INDD는 변경하지 않았습니다.

폰트 설치 파일은 기존11종ZIP과 제공하신YES24.ttf를 사용합니다. [설치·라이선스 안내](../editing-fonts/README_KO.md)
