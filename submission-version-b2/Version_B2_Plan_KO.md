# B2 — 한 문장, 같은 기준

A안과 기존 B안은 보존하고, 비교 기준을 통일한 별도 수정본을 만든다.

## 편집 목적

‘진심입니다’라는 같은 말이 폰트만 달라졌을 때 어떻게 다른 말투로 들리는지, 설명을 읽기 전에 그림으로 확인하는 책이다. 폰트의 형태 관찰을 먼저 보여주고, 본문 마지막6쪽에서 검토한15개 유행어에 적용한다. 느낌의 판단은 편집자 정슬기의 해석이며 측정값으로 감정을 증명하지 않는다.

## 비교에서 고정하는 것

- 문장: ‘진심입니다’. 확대 대상은 그 문장의 두 번째 글자 ‘심’만 사용한다.
- 본문 관찰12쪽: 문장64pt·첫 기준선182pt. 모든 쪽에 같은 Noto Sans 기준을 함께 둔다.
- 확대 도해: 기준과 선택 폰트 모두128pt. 원점·기준선·격자·확대율을 고정하며 글자의 몸집에 맞춰 확대하지 않는다.
- 색: 검정은 실제 획, 분홍은 실제로 닫힌 빈틈, 빨강은 실제 잉크 경계. 회색은 공통 격자와 기준이다.
- 문장 폭 막대: 폰트의 실제 글자 진행 폭을1:1 포인트로 표시한다. 감정 점수나 커닝값이 아니다.
- 관찰과 인상: 같은 ‘심’에서 보이는 구체적인 특징을 먼저 쓰고 ‘내겐…’으로 해석을 구분한다.

## 28면 구성

| 파일 면 | 지면 쪽수 | 내용 |
|---|---|---|
|1|없음|표지: 같은 ‘심’의 두 실제 골격, 문서 내부에 포함된 사진|
|2|01|목차|
|3|02|같은64pt 문장 두 개로 읽는 기준 제시|
|4–15|03–14|폰트12종: 같은 문장 폭·같은 ‘심’ 확대·관찰·내 인상|
|16–17|15–16|12종 ‘진심입니다’를 모두32pt로 한눈에 비교|
|18–19|17–18|12종 ‘심’을 모두96pt, 같은 격자로 비교|
|20|19|앞의 관찰을 인상으로 연결하는 세 쌍 비교|
|21|20|검은 환기 페이지와 응용부 시작|
|22–27|21–26|검토한15개 유행어: 같은 문구·크기·색에서 폰트만 변경|
|28|없음|뒷표지·출처|

크기가 다른64/128/32/96pt는 각 비교 묶음의 목적에 맞춰 명시하며, 같은 묶음 안에서는 모든 폰트가 같은 크기이다. 서로 다른 크기의 견본끼리 몸집을 비교하지 않는다. 문구를 바꾼 감정 실험, 폰트마다 다른 부위의 확대, 임의의 감정 좌표 점수는 넣지 않는다.

## 인쇄와 편집

A5 세로148×210mm, 표지 포함28쪽. 내지는 목차부터01–26, 앞뒤 표지에는 번호 없음. 3mm 도련, 인쇄PDF는 A3 가로14면/7장에 재단선 포함. 첫 앞면28｜1, 뒤2｜27이며 인쇄번호는 표지 포함 파일 순서이다. A3 양면·짧은 쪽 넘김·실제 크기100%, 소책자·모아찍기·용지맞춤 해제.

편집용 IDML은 실제 텍스트와 실제 폰트 윤곽 벡터를 함께 사용한다. 문장 견본과 해설은 텍스트로 수정할 수 있다. 확대 분석 도해는 폰트의 실제 윤곽을 추출한 벡터다. 사진은 내부에 포함한다. PDF는 이 환경에서 IDML을 직접 렌더한 검토/인쇄본이며 실제 Adobe InDesign 실행과 프리셋 내보내기, 실물 출력은 미검증이다.

원문과 승인 예문은 별도 archive에 보존한다. 응용 지면의 발췌는 승인 문구를 유지한다. 폰트12종은 기존과 동일하며 YES24 파일은 사용자가 제공한 개인 보유 파일이다.
