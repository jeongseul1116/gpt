# 추가 원문 보존 안내

기존 원문 11개와 보존 파일 14개는 그대로 유지하고, 새 원문 A05–A10을 별도 폴더에 추가했다. 전체 수집 원문은 17개이며, 현재 책은 B04를 제외한 16개를 사용한다.

A05는 6행의 원문과 분리 자모·띄어쓰기를 보존했다. A10은 무띄어쓰기 원문과 마지막 공백 두 칸을 보존했다. 각 TXT는 자동 줄바꿈 없이 끝난다. JSON의 text는 TXT와 문자 단위로 일치한다.

A07·A08·A09는 한 메시지의 목록을 편집 항목으로 분리했다. 그 메시지 자체는 user_list_capture.txt에 보존했다. 별도로 알려준 사용 예문은 user_usage_examples.json 및 capture TXT에서 관리한다.

제목과 ID는 편집 메타데이터이며 원문에 포함되지 않는다. 교수님 이미지 밈은 사용자의 제외 지시에 따라 추가하거나 전사하지 않았다.
