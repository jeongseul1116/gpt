# B3 — 말투 접수 광고판

[전체28면 PDF](Meme_Font_Book_Version_B3_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B3_28p.idml) · [A3 양면 인쇄 PDF](Meme_Font_Book_Version_B3_A3_Duplex_28p.pdf)

앞표지는 참고한 길거리 광고처럼 검정·노랑·빨강·파랑과 큰 제목으로 구성했습니다. ‘무섭다’ 사진은 뒷표지에 원본 그대로 내장했습니다. 관찰부에는 접수번호와 대조 제목, 응용부에는 좌우 접수표·광고3단을 적용했습니다.

같은 문장64pt·같은‘심’128pt의 비교 좌표와 실제 윤곽·속공간은 B2와 같습니다. 승인 예문15개도 보존했습니다. 기존 A·B·B2는 별도 폴더로 남겨두었습니다.

## 쪽수

**‘들어가며’가1쪽입니다.** 앞표지와 목차는 무쪽수, 파일3면부터 지면01–25, 뒷표지도 무쪽수입니다. InDesign Section과 PDF PageLabels까지 맞췄습니다. 목차는 폰트02–13, 전체비교14–17, 관찰에서인상으로18, 유행어적용19–25를 가리킵니다.

## 출력과 편집

A3 가로·양면·짧은 쪽 넘김·실제100%. 소책자·모아찍기·용지맞춤 해제. 표지 포함28면의 인쇄 짝은 첫28｜1, 뒤2｜27이며 들어가며의 지면1쪽은 파일3면입니다. 7장/14면,3mm도련·재단선·100mm확인선을 포함합니다. 먼저 앞뒤1장을 시험 출력하세요.

사진과 도해는 IDML 내부에 포함됩니다. 글자 견본과 원고는 텍스트, 확대 분석은 실제 폰트 윤곽 벡터입니다. 기존 폰트11종과 사용자 제공YES24.ttf를 사용합니다. [폰트 설치 안내](../editing-fonts/README_KO.md)

PDF는 IDML 직접렌더본입니다. 실제Adobe 실행·고품질 인쇄 프리셋 내보내기·실물 출력은 미검증입니다. 검수 보고서는qa, 파일 해시는SHA256SUMS.txt, 원문은archive에 있습니다.
