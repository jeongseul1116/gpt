## 이번에 바꾼 비교

문장은 **진심입니다**, 확대 대상은 그 문장의 **심**으로 고정했습니다. 12종 모두 문장 폭 → 같은 글자 확대 → 구체적인 형태 관찰 → 내가 느낀 인상 순서입니다. 모든 폰트 관찰 쪽에 같은 Noto Sans 기준을 함께 놓았습니다. 본문 마지막6쪽에서만 검토한15개 유행어를 적용합니다.

검정은 실제 획, 분홍은 실제로 닫힌 빈틈, 빨강은 실제 잉크 경계입니다. 윤곽과 빈틈은 실제 폰트에서 추출했으며 임의로 그리지 않았습니다. 글자별 크기에 맞춰 확대하지 않아 같은 포인트에서의 몸집 차이도 보입니다. 실제 윤곽이 열려 있는 궁서·붓 글자는 닫힌 빈틈으로 채우지 않습니다.

- 관찰12쪽: 문장64pt, ‘심’128pt. 원점·기준선·확대율·도해 방법 모두 동일합니다.
- 전체 비교:12종 문장32pt,12종 ‘심’96pt를 각각 같은 크기로 모았습니다.
- 인상은 편집자의 해석입니다. 폭의 수치나 잉크 면적이 감정의 객관적 점수를 의미하지 않습니다.
- 표지 포함28면, 목차부터 지면번호01–26. 앞뒤 표지에는 쪽수가 없습니다.

IDML에는 문장 견본과 해설을 편집 가능한 텍스트로, 분석 도해를 실제 폰트 윤곽 벡터로 넣었습니다. 표지 사진은 문서 안에 포함했습니다. 기존 폰트11종과 제공하신 YES24.ttf를 사용하며 새 폰트는 필요하지 않습니다. [폰트 설치 안내](../editing-fonts/README_KO.md)

## 인쇄

A3 가로 / 양면 / **짧은 쪽 넘김** / 실제크기100%. 소책자·모아찍기·용지맞춤을 해제합니다.7장·14면이며3mm도련과 재단선을 포함합니다. 첫 앞면은28｜1, 뒤는2｜27입니다. 인쇄 짝의 번호는 표지 포함 파일 순서입니다. 바깥 재단선을 따라 자르고 가운데를 접습니다. 먼저 첫 양면을 시험 출력해100mm확인선과 방향을 확인하세요.

## 확인 범위

내용·좌표·실제 글자 잉크 경계·28면 순서·내부 사진·도련·재단선·100%배치를 검사했습니다. 보고서는qa, 파일 해시는SHA256SUMS.txt에 있습니다. 기존 A/B의84개 대상 파일은 해시가 동일합니다.
