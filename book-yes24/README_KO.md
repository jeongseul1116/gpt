# 예스체 적용본 — 밈 폰트 도감 32쪽

사용자가 제공한 `YES24.ttf`의 **예스체(YES24) Regular**를 기존 A5 32쪽 시안에 우선 적용했습니다. 별도 Bold가 없는 서체이므로 제목·본문·해설 340개 텍스트 모두 Regular를 사용하고, 크기와 색·간격으로 위계를 나눴습니다.

## 열기

1. 사용자가 올렸던 `YES24.ttf`를 Windows에서 설치합니다. 이미 설치했다면 다시 설치하지 않아도 됩니다.
2. InDesign을 실행하고 `Meme_Typography_YES24_32p.idml`을 엽니다.
3. 글꼴 목록의 **예스체** 또는 **YES24**, 스타일 **Regular**를 확인합니다.
4. 텍스트 넘침과 쪽 순서를 확인한 뒤 `.indd`로 저장합니다.

IDML 열기에 문제가 있으면 `Create_YES24_InDesign.jsx`를 InDesign의 **창 → 유틸리티 → 스크립트 → 사용자** 폴더에 넣고 스크립트 패널에서 두 번 클릭합니다. 저장할 폴더를 고르면 InDesign 자체가 새 INDD를 저장하고 IDML을 내보냅니다. 예스체가 설치되지 않았다면 안내 후 중단하며 다른 글꼴로 자동 대체하지 않습니다. 기존 파일은 덮어쓰지 않습니다.

실제 InDesign 실행 환경은 없어 IDML 열기와 JSX 실행은 미검증입니다. ZIP·XML·리소스 참조·글꼴 지정·스크립트 구문·내장 데이터 일치 및 별도 렌더러의 미리보기를 검사했습니다. INDD 바이너리를 이 환경에서 직접 생성한 파일은 아닙니다.

## 바뀐 지면

- 제목·본문·해설을 예스체 Regular로 적용했습니다.
- 기존 명조체·Bold 분석을 예스체의 직선 골격, 짙은 획과 크기·간격에 관한 분석으로 바꿨습니다.
- 28–29쪽 실험실은 같은 예스체를 22·32·44pt로 비교합니다.
- 글꼴의 높이 지표를 반영해 좁은 텍스트 프레임 7곳의 크기와 행간을 조정했습니다.
- A5 148×210mm, 32쪽, 본문 15개 펼침면과 표지·뒷표지 각 1쪽, 사방 도련 3mm 구성입니다.
- 26–27쪽의 12번째 밈은 계속 수집용 지면으로 남겼습니다.

원문 11개의 공백·줄바꿈·이모지와 별도 `archive/`는 변경하지 않았습니다. 예스체가 지원하지 않는 A01·B02·B04의 문자 얼굴·점자·이모지는 기존 벡터 블록 4개를 그대로 유지했습니다. 기본 본문과 해설은 편집 가능한 텍스트입니다.

## 글꼴 파일과 출처

업로드된 파일의 실제 이름은 YES24 / 예스체, 스타일 Regular, PostScript 이름 YES24입니다. 이 시안은 그 글꼴을 이름으로 참조하며 **폰트 바이너리를 IDML이나 ZIP에 포함하지 않습니다.** 사용자가 이미 가진 TTF를 설치해 사용합니다.

폰트 내부 저작권과 배포 조건은 무료 재배포 허용으로 확정하지 않았습니다. `font_identity.json`과 `font_audit.md`에 확인한 메타데이터와 공식 페이지 접근 결과를 기록했습니다. 특수 문자 벡터를 만드는 데 사용한 Noto·DejaVu 서체의 출처와 라이선스 기록은 `vector_font_records/`에 별도로 보존했습니다.

미리보기는 해당 YES24 파일을 직접 읽어 생성한 참고 렌더이며 InDesign에서 내보낸 결과는 아닙니다. 기존 밈의 최초 게시자는 확인하지 않았습니다.
