# B6 — 글자는 그대로, 빈틈이 보이는 비교

사용자가 제시한 폰트 제작·커닝 도해를 참고해, 반복되던 두 비교 펼침면의 목적을 나눴다. 비교 문장은 ‘북쪽에계신메리메리’이며 B5의 표지·인트로·12개 폰트 분석·최종 적용과 B급 인상을 유지한다.

## 14–15쪽: 같은 글자, 틈만 수리

네 폰트의 문장 전체를 각각 기본 조판과 편집 간격 조정 후로 비교한다. 아홉 글자의 실제 32pt 윤곽은 바꾸지 않고, 지정한 글자 사이에서 뒤 글자들의 가로 위치만 옮긴다. 전후 모두 동일한 크기의 칸에 실제 윤곽을 기준으로 중앙 정렬한다. 주황 면은 마주 보는 실제 획 사이의 빈틈을 따라 그리며, 화살표와 pt 값으로 이 책에서 적용한 조정을 표시한다. 이는 폰트에 저장된 원래 커닝값을 밝히는 자료가 아니라, 눈으로 간격 차이를 보는 편집 실험이다.

## 16–17쪽: 빈틈도 옆모양을 닮는다

문장 전체에서 ‘쪽에’, ‘계신’, ‘메리’를 먼저 찾아 표시한다. 그 문장에 연결된 두 글자의 모양을 같은 64pt로 확대하고, 마주 보는 획 사이의 실제 빈틈을 주황 면으로 보여준다. Noto Sans와 은궁서가 같은 글자쌍에서 어떤 모양의 빈틈을 만드는지 비교한다. 문장 전체는 같은 20pt이며, 두 글자 확대는 문맥에 붙은 설명 도해다.

## 유지하는 구성

A5 148×210mm, 표지 포함28면, 목차 무쪽수·들어가며1쪽을 유지한다. 페이지별 폰트 분석과 원문 보존, 마지막15개 유행어의 승인 예문·인상 문구는 B5 그대로다. 출처와 본문은 왼쪽 정렬, 비교 문장·표지 문구는 지정 영역의 가로·세로 중앙 정렬을 유지한다. 원본 사진은 뒷표지에 내부 내장한다.

인쇄는 A3가로7장·14면, 첫28｜1·뒤2｜27 조판이며 실제100%, 짧은 쪽 양면이다. 3mm도련·재단선·100mm확인선을 포함한다. 이전판 A·B·B2·B3·B4·B5는 보존한다.
