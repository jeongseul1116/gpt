# B7 — 아홉 글자, 여덟 간격 전부

[28쪽 PDF](Meme_Font_Book_Version_B7_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B7_28p.idml) · [A3 인쇄 PDF](Meme_Font_Book_Version_B7_A3_Duplex_28p.pdf)

비교 문장은 **북쪽에계신메리메리**입니다. 인접한 모든 간격을01–08로 표시했습니다. ‘북–쪽 / 쪽–에 / 에–계 / 계–신 / 신–메 / 메–리 / 리–메 / 메–리’이며, 반복되는 ‘메리’도06·08번으로 따로 다룹니다.

- 12종 폰트 분석의 기준·선택24개 문장에8개 빈틈을 전부 표시했습니다. 주황 면은 실제 마주 보는 획 사이의 빈틈이며 분홍은 닫힌 속공간입니다. 폰트마다 일부 간격만 골라내지 않습니다.
- 지면14–15쪽: 4개 폰트의 같은32pt 전후8개 문장에8개 간격을 모두 표시했습니다. 각 폰트의8개 편집 조정값도 표로 적었습니다. 글자 모양과 크기는 그대로이며 가로 위치만 바꿉니다. 조정값은 이 책의 편집 실험값으로, 폰트에 저장된 원래 커닝값이 아닙니다.
- 지면16–17쪽: Noto Sans와 은궁서에서 각각 모든8쌍을2열×4행으로 배치했습니다. 문장 전체20pt에서01–08 위치를 먼저 보고, 각 글자쌍과 빈틈 도형을 동일한36pt로 비교합니다. 특정 세 쌍만 발췌하지 않습니다.

B급 인상, 표지 오브제·비교 문장의 가로·세로 중앙 정렬, 일반 설명의 왼쪽 정렬을 유지했습니다. 원본 사진은 뒷표지에 내부 내장했습니다. 승인된15개 유행어 문구와 사용 예문은 보존했습니다.

A5 28면, 목차 무쪽수·들어가며부터1–25쪽입니다. 인쇄는 A3가로7장/14면·짧은 쪽 양면·실제100%입니다. 소책자·모아찍기·용지맞춤을 해제합니다. 첫28｜1·뒤2｜27은 표지 포함 파일 순서입니다. 3mm도련·재단선·100mm확인선을 포함합니다.
