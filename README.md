# 마참내! 폰트도 웃길 수 있다

친구들에게 나눠줄 밈 폰트 도감. 정슬기 기획과 사용자 제공 원문 11개를 바탕으로 작성한 A5 세로·중철·32쪽 디자인 초안입니다.

## 최신: 예스체(YES24) 적용본

사용자가 올린 `YES24.ttf`의 **예스체 Regular**를 제목·본문·해설 340개 텍스트에 적용했습니다. AA·이모지 벡터 4개와 공백·줄바꿈을 보존한 원문 아카이브는 유지했습니다. 별도 Bold 합성 없이 크기·색·간격을 조정했습니다.

- [예스체 적용 IDML 다운로드](https://github.com/jeongseul1116/gpt/raw/refs/heads/main/book-yes24/Meme_Typography_YES24_32p.idml)
- [전체 패키지 다운로드](https://github.com/jeongseul1116/gpt/raw/refs/heads/main/Meme_Typography_YES24_package.zip)
- [예스체 32쪽 미리보기](book-yes24/preview_YES24_32p.jpg)
- [열기·설치 방법과 검증 범위](book-yes24/README_KO.md)

사용자가 가진 YES24.ttf를 먼저 설치해야 합니다. 폰트 원본은 재배포하지 않고 IDML과 스크립트가 글꼴 이름으로 참조합니다. IDML 열기가 실패하면 패키지의 `Create_YES24_InDesign.jsx`를 InDesign 스크립트 패널에서 실행하는 대체 방법이 있습니다.

실제 InDesign 실행 환경이 없어 열기·실행·최종 조판은 미검증입니다. 파일 구조, 글꼴 지정, 글리프 지원, 원문 보존, 스크립트 구문 및 별도 렌더러의 미리보기는 검사했습니다.
