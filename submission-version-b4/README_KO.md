# B4 — 가운데 정렬과 형태에서 말투로

[28쪽 PDF](Meme_Font_Book_Version_B4_28p_Review.pdf) · [편집용 IDML](Meme_Font_Book_Version_B4_28p.idml) · [A3 인쇄 PDF](Meme_Font_Book_Version_B4_A3_Duplex_28p.pdf)

표지 하단 4개 폰트 이름, 확대 ‘심’ 24개와 종합 비교 12개를 실제 윤곽 기준으로 각 칸의 가로·세로 중앙에 맞췄습니다. 포인트와 글자 모양은 유지합니다. 표지 라벨은 편집 문단에도 CenterAlign을 적용했고, 설명문은 왼쪽 정렬입니다.

지면 14–15쪽은 같은 32pt ‘진심입니다’에 실제 닫힌 빈틈을 표시하고, 측정한 검은 면의 비율과 다섯 글자의 몸집·사이 틈을 보여줍니다. 회색은 Noto Sans 기준, 검정은 선택 폰트이며 모든 폰트가 같은 축을 씁니다. 비율의 분모는 각 문장 진행 폭×48pt, 검은 면은 실제 글자 모양의 합집합으로 측정했습니다. ‘약’으로 표시하고 감정 점수와 구분합니다. 가로 범위 그림은 실제 윤곽 사이의 틈이며 디자이너의 커닝 설정값이 아닙니다.

지면 18쪽은 형태에서 내가 느낀 말투를 거쳐 크게 선언할 때·차분히 안내할 때·다정히 건넬 때 등 선택할 상황으로 연결합니다. 실제 밈 적용 15개는 마지막에 유지하고 승인 원고를 그대로 보존했습니다.

28면·A5이며 목차는 무쪽수, 들어가며부터 1–25쪽입니다. ‘무섭다’ 사진은 뒷표지에 원본 그대로 내장했습니다. A3 가로 7장/14면·짧은 쪽 양면·실제 100%로 인쇄합니다. 소책자/모아찍기/용지 맞춤은 해제합니다. 첫 28｜1, 뒤 2｜27은 표지 포함 파일 순서입니다. 3mm 도련·재단선·100mm 확인선을 포함합니다.

IDML은 텍스트·실제 폰트 벡터·내장 사진을 사용합니다. 기존 폰트 11종과 제공된 YES24.ttf가 필요합니다. [폰트 설치](../editing-fonts/README_KO.md)

PDF는 IDML 직접 렌더본이며 실제 Adobe 실행·프리셋 내보내기·실물 출력은 미검증입니다. qa는 측정·정렬·내용·구조·인쇄 검수 보고서, archive는 원문과 승인 예문입니다. 파일 해시는 SHA256SUMS.txt입니다.
