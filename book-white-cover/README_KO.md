# 흰 표지 + 무섭다 사진 적용본

사용자 제공 사진을 배경 분리한 편집본으로 만들어 **흰 바탕의 앞표지**에 배치했습니다. 검정 예스체 제목과 사진의 빨간 말풍선을 중심으로 구성했습니다. 사진은 책의 표지 이미지이며 원문 목록에 새 밈을 추가한 것은 아닙니다.

## InDesign에서 열기

1. ZIP을 풀어 **폴더 전체**를 보관합니다.
2. 사용자가 올린 `YES24.ttf`를 설치합니다. 설치돼 있다면 다시 설치할 필요는 없습니다.
3. `Meme_Typography_WhiteCover_32p.idml`을 InDesign에서 엽니다.
4. `Links/cover_cutout.png`를 IDML 옆의 Links 폴더에 그대로 두세요. 링크가 누락됐다고 나오면 InDesign 링크 패널에서 이 PNG를 다시 연결합니다.
5. 사진·서체·텍스트 넘침을 확인한 뒤 `.indd`로 저장합니다.

**IDML 파일만 따로 내려받거나 이동하면 표지 사진 링크가 누락될 수 있으므로 ZIP 전체를 사용하세요.**

## InDesign 내부 생성 대체 방법

IDML 열기에 문제가 있으면 ZIP을 푼 전체 폴더를 InDesign **창 → 유틸리티 → 스크립트 → 사용자** 폴더 안에 넣습니다. `Create_Cover_InDesign.jsx`와 `Links/`를 함께 유지한 상태로 스크립트 패널에서 실행합니다.

이 스크립트는 예스체 Regular를 확인하고 새 문서에 사진을 비율 유지 배치해 `.indd`로 저장합니다. 사진을 문서에 포함하는 동작도 시도하며, 포함하지 못하면 링크를 유지해 보고합니다. 포함이 확인되기 전에는 풀어둔 Links 폴더를 삭제하지 마세요. 기존 파일은 덮어쓰지 않습니다.

## 유지한 내용과 검사

- A5 148×210mm, 32쪽, 표지·뒷표지 각 1쪽 + 본문 15개 펼침면, 도련 사방 3mm입니다.
- 앞표지와 31쪽의 사진 출처 문구를 갱신했습니다. 나머지 30쪽은 예스체 적용본과 동일합니다.
- 원문 아카이브 11개와 AA·이모지 벡터 4개는 그대로 보존했습니다.
- 제목·본문·해설 339개 텍스트는 YES24 Regular를 사용합니다. 폰트 원본은 동봉하지 않습니다.
- 이미지 파일은 사용자 사진을 바탕으로 배경 분리한 파생본입니다. 원래 해상도를 검증한 고해상도 원본이라는 뜻은 아닙니다.
- ZIP·XML·글꼴 지정·리소스 참조·이미지 경로·스크립트 구문·페이지 데이터 일치와 별도 렌더러 미리보기를 검사했습니다.
- **실제 InDesign 실행 환경이 없어 IDML 열기, 스크립트 실행과 최종 조판은 미검증입니다.** 미리보기는 InDesign 내보내기 결과가 아닙니다.
