# 표지 이미지가 파일 내부에 들어 있는 IDML

**Meme_Font_Book_28p_Embedded_Image.idml 파일 하나를 내려받아 InDesign에서 엽니다.** 별도의 Links폴더·사진파일·복구스크립트는 필요 없습니다.

표지 PNG의 전체922,981바이트를 IDML의 Image/Properties/Contents 안에 넣고 Embedded상태로 저장했습니다. 사진은874×1275px·300dpi이며 기존 사진과 바이트가 같습니다. 실제 외부 파일을 가리키는 이미지 경로는 없습니다.

마지막으로 전달한 목차01쪽 시작·표지포함28면을 기준으로 했으며, 본문·폰트 지정·쪽수·표지 위치와 크기는 그대로입니다. 사용자의 컴퓨터에서 이후 직접 수정한 내용은 이 파일에 반영할 수 없으므로, 이 파일은 마지막 전달본을 기준으로 합니다.

폰트는 이전에 제공한11종과 사용자가 올린 YES24.ttf를 설치하면 됩니다. InDesign에서 연 뒤 INDD로 저장할 수 있습니다.

Adobe의 IDML 사양과 실제 InDesign내보내기 파일의 임베드 형식을 확인했고, 내부PNG의 바이트일치·문서구조·기존내용 보존을 검사했습니다. 실제 Adobe InDesign에서 열기 테스트는 이 환경에서 하지 못했습니다.

이전의 image-link-repair와 외부 Links폴더 방식은 이 파일에 필요하지 않습니다. 디자인 검토PDF와 인쇄용PDF는 변경이 없습니다.
